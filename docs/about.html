English

Project scope

This project evaluates genomic prediction methods for production and fruit-quality traits in papaya using multi-allelic SSR markers.

The prediction methods are:

  • Bayesian ridge regression;
  • BayesA;
  • BayesB;
  • BayesB with inclusion probability \(10^{-5}\);
  • BayesC;
  • Bayesian Lasso;
  • RR-BLUP;
  • GBLUP.

The Bayesian models are fitted with BGLR (Pérez and Campos 2014). RR-BLUP and GBLUP are included as frequentist reference methods.

Validation design

The predictive comparison uses the same five family-stratified folds for every model. Each fold contains 30 validation individuals and 120 training individuals, with three individuals from each family in validation.

Marker filtering, allele coding, imputation, centering, and genomic-matrix construction are recalculated from the training individuals of each fold.

Analytical decisions

  • Individual identifiers are obtained from the Genealex worksheet.
  • The alphanumeric identifier 144B is preserved.
  • SSR loci are represented by allele dosages from 0 to 2.
  • Triallelic loci retain one dosage column for each observed allele.
  • Block and family are fitted as categorical fixed effects.
  • DIC is used only as a diagnostic for Bayesian models.
  • Correlation, RMSE, and MAE are used to compare all prediction methods.
  • Trait-specific rankings are reported separately.

Português

Escopo do projeto

Este projeto avalia métodos de predição genômica para características de produção e qualidade de frutos em mamoeiro utilizando marcadores SSR multialélicos.

Os métodos de predição são:

  • regressão ridge Bayesiana;
  • BayesA;
  • BayesB;
  • BayesB com probabilidade de inclusão \(10^{-5}\);
  • BayesC;
  • Lasso Bayesiano;
  • RR-BLUP;
  • GBLUP.

Os modelos Bayesianos são ajustados com o BGLR (Pérez and Campos 2014). RR-BLUP e GBLUP são incluídos como métodos frequentistas de referência.

Desenho de validação

A comparação preditiva utiliza os mesmos cinco folds estratificados por família em todos os modelos. Cada fold contém 30 indivíduos de validação e 120 indivíduos de treinamento, com três indivíduos de cada família na validação.

O filtro dos marcadores, a codificação dos alelos, a imputação, a centralização e a construção da matriz genômica são recalculados com os indivíduos de treinamento de cada fold.

Decisões analíticas

  • Os identificadores dos indivíduos são obtidos da planilha Genealex.
  • O identificador alfanumérico 144B é preservado.
  • Os locos SSR são representados por dosagens alélicas de 0 a 2.
  • Locos trialélicos mantêm uma coluna de dosagem para cada alelo observado.
  • Bloco e família são ajustados como efeitos fixos categóricos.
  • O DIC é utilizado apenas como diagnóstico dos modelos Bayesianos.
  • Correlação, RMSE e MAE são utilizados para comparar todos os métodos.
  • Os rankings são apresentados separadamente para cada característica.
