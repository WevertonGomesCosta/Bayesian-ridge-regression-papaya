1. Objective

This module documents the complete cross-validated fitting of seven genomic prediction methods for ten papaya traits. The 350 fits are executed once by analysis/03_models_fit.R; this page reads and presents the resulting canonical object without refitting models. The same five deterministic, family-stratified folds are used for every method and trait.

The complete analysis contains:

\[ 10\ \text{traits} \times 5\ \text{folds} \times 7\ \text{methods} = 350\ \text{fits}. \]

All methods are fitted exclusively with BGLR (Pérez and Campos 2014):

  1. RR-BLUP, implemented with the BGLR BRR component and the complete marker matrix M (Endelman 2011);
  2. BayesA with M;
  3. BayesB with M;
  4. BayesB2 with M and a zero-effect probability operationally fixed near \(10^{-5}\);
  5. BayesC with M;
  6. Bayesian Lasso with M (Park and Casella 2008), with the shrinkage parameter lambda fixed at the global value deterministically calibrated by the BGLR default rule;
  7. GBLUP with the genomic relationship matrix G and the BGLR RKHS component.

BayesA and BayesB follow the genomic-prediction framework introduced by Meuwissen et al. and its subsequent Bayesian-alphabet development (Meuwissen et al. 2001; Habier et al. 2011).

RR-BLUP and Bayesian ridge regression are not treated as separate methods. The Gaussian marker-effect model implemented by model = "BRR" is the RR-BLUP implementation used in this project.

2. Analytical contract

The matrices constructed in Module 02 are used without fold-specific reconstruction:

  • X contains the intercept and the family fixed-effect coding;
  • M contains the 72 centered allele-dosage columns;
  • G contains the additive genomic relationships;
  • each fold identifies 30 validation individuals and 120 training individuals.

BGLR includes an intercept by default. Therefore, the intercept column is removed from X, leaving only the family columns to be passed through the FIXED component.

For each trait and fold, only a copy of the phenotype vector is changed. The 30 validation observations are replaced by NA; X, M, and G remain global and unchanged.

The MCMC settings follow the main methods section of the reference article (Silva et al. 2021):

  • 1,000,000 iterations;
  • 200,000 burn-in iterations;
  • thinning equal to 4;
  • 200,000 retained posterior samples.

The BGLR default prior allocation parameter is made explicit with R2 = 0.5. For the Bayesian Lasso, lambda is held fixed at the deterministic lambda0 obtained from BGLR’s own calibration. Because the predictor contains two ETA terms (family FIXED and genomic BL), BGLR allocates R2/2 to the BL component. Matrix M is global, so MSx and lambda0 are also global and identical across traits and folds.

3. Single canonical execution

Model fitting is separated from presentation. The complete analysis is executed explicitly with:

Rscript --vanilla analysis/03_models_fit.R

The script performs the 350 trait-fold-method fits sequentially in one R session. Deterministic seeds are defined for every fit.

Native BGLR files are written directly to output/models/bglr/Trait/Fold/Method/. The compact canonical analytical object is output/models/models_object.rds. Rendering this page never fits or refits a genomic model.

  length(settings$traits) * length(settings$folds) * length(settings$methods)

  expected_fits == 350L,

  nrow(cv_predictions) == 150L * length(settings$traits) * length(settings$methods),
