1. Objective

This module fits seven genomic-prediction methods to ten papaya traits using the same five family-stratified cross-validation folds created in Module 02. The objective is to show, step by step, how the statistical model is specified, how each genomic method is represented in BGLR, how out-of-fold (OOF) predictions and genomic values are obtained, and how MCMC diagnostics are calculated.

The complete analysis contains

\[ 10\ \text{traits} \times 5\ \text{folds} \times 7\ \text{methods} = 350\ \text{fits}. \]

The seven methods are RR-BLUP, BayesA, BayesB, BayesB2, BayesC, Bayesian Lasso (BL), and GBLUP. RR-BLUP is implemented through the BGLR BRR component, so RR-BLUP and Bayesian ridge regression are not treated as separate methods in this project (Endelman 2011; Pérez and Campos 2014).

The model-fitting code is contained entirely in this R Markdown document. A normal workflowr build presents the existing fitted results without repeating the 350 fits. A complete refit is performed only when the explicit execution switch described in Section 8 is enabled.

3. Statistical model

For every trait, the common model is

\[ \mathbf y = \mathbf 1\mu + \mathbf X_F\boldsymbol\beta_F + \mathbf g + \boldsymbol\varepsilon, \]

where \(\mu\) is the intercept, \(\mathbf X_F\boldsymbol\beta_F\) is the family fixed effect, \(\mathbf g\) is the genomic component, and \(\boldsymbol\varepsilon\) is the residual vector.

3.1 Intercept and family fixed effect

BGLR fits an intercept automatically. Therefore, the intercept column created in Module 02 is removed before X is supplied as a FIXED term. The remaining columns code family effects and are estimated without shrinkage.

X_fixed <- X[
  ,
  colnames(X) != "(Intercept)",
  drop = FALSE
]

colnames(X_fixed)
[1] "FAM2"  "FAM3"  "FAM4"  "FAM5"  "FAM6"  "FAM7"  "FAM8"  "FAM9"  "FAM10"

Here, model = "FIXED" refers to the treatment of the family regression coefficients as fixed effects. This use of FIXED is different from type = "FIXED" in the Bayesian Lasso, which is explained in Section 6.6.

3.2 Genomic component

For the six marker-effect methods,

\[ \mathbf g = \mathbf M\boldsymbol\alpha, \]

so the model becomes

\[ \mathbf y = \mathbf 1\mu + \mathbf X_F\boldsymbol\beta_F + \mathbf M\boldsymbol\alpha + \boldsymbol\varepsilon. \]

The methods differ mainly in the prior assigned to marker effects \(\boldsymbol\alpha\). GBLUP instead models genomic values directly as

\[ \mathbf g \sim N(\mathbf 0,\mathbf G\sigma_g^2). \]

6.1 RR-BLUP

RR-BLUP is implemented with BGLR’s BRR component. Marker effects have a common Gaussian prior variance, producing ridge-type shrinkage of all marker effects (Endelman 2011; Pérez and Campos 2014).

6.2 BayesA

BayesA assigns marker-specific variances, allowing markers to undergo different amounts of shrinkage (Meuwissen et al. 2001; Habier et al. 2011).

6.3 BayesB

BayesB combines a point mass at zero with a continuous distribution for nonzero effects. Consequently, the model can simultaneously perform shrinkage and variable selection.

6.4 BayesB2

BayesB2 is the project name for a specific BGLR BayesB parameterization; it is not a separate BGLR model name. The intended probability of a zero marker effect is

\[ P(\alpha_j=0)=10^{-5}. \]

BGLR parameterizes BayesB through probIn, the probability that a marker is included with a nonzero effect. Therefore,

\[ probIn = 1-10^{-5}=0.99999. \]

counts = 10^6 makes the beta prior for probIn highly concentrated around that value.

6.5 BayesC

BayesC also allows a marker effect to be zero, but nonzero marker effects share a common variance rather than marker-specific variances.

6.6 Bayesian Lasso and the fixed lambda

The Bayesian Lasso uses a double-exponential marginal prior for marker effects (Park and Casella 2008). In BGLR, the shrinkage parameter \(\lambda\) can be updated during MCMC or held fixed. In this analysis it is held fixed at the value obtained from BGLR’s own default calibration.

This is the second, distinct use of the word FIXED in Module 03:

  • model = "FIXED" describes the unpenalized family effects;
  • type = "FIXED" inside model = "BL" means that lambda is not updated during MCMC.

BGLR allocates the global R2 among linear terms. The predictor contains two terms: the family FIXED term and the genomic BL term. Hence the BL term receives

\[ R^2_{BL}=\frac{0.5}{2}=0.25. \]

For the centered marker matrix, the calibration uses

\[ MS_x= \frac{1}{n}\sum_j\sum_i m_{ij}^2- \sum_j\bar m_j^2, \]

and

\[ \lambda_0^2= 2\frac{1-R^2}{R^2_{BL}}MS_x. \]

The value is calculated directly from the Module 02 marker matrix.

BL_N_LINEAR_TERMS <- 2L
BL_COMPONENT_R2 <- R2_PRIOR / BL_N_LINEAR_TERMS

6.7 GBLUP

GBLUP uses the genomic relationship matrix G rather than individual marker effects. In BGLR it is represented by an RKHS term with K = G, which gives the genomic values the covariance structure defined by G.

8.3 Validate the fixed lambda during fitting

The fixed BL value is checked directly in the fitted BGLR object and against the native lambda file. This validation is the same for every BL fit and is kept separate from the general fitting function.

validate_fixed_bl <- function(
  fit,
  save_prefix,
  run_id,
  method_name,
  lambda_update_warning_count
) {
  result <- list(
    lambda = NA_real_,
    native_value = NA_real_,
    serialization_error = NA_real_,
    native_valid = NA,
    valid = NA
  )

  if (method_name != "BL") {
    return(result)
  }

  result$lambda <- as.numeric(fit$ETA$genomic$lambda)
  lambda_error <- abs(result$lambda - BL_LAMBDA)

  lambda_trace <- scan(
    paste0(save_prefix, "ETA_genomic_lambda.dat"),
    quiet = TRUE
  )

  result$native_value <- if (length(lambda_trace) > 0L) {
    lambda_trace[1]
  } else {
    NA_real_
  }

  result$serialization_error <- if (is.finite(result$native_value)) {
    abs(result$native_value - BL_LAMBDA)
  } else {
    Inf
  }

  result$native_valid <-
    length(lambda_trace) == RAW_SAVED_SAMPLES &&
    all(is.finite(lambda_trace)) &&
    all(lambda_trace > 0) &&
    length(unique(lambda_trace)) == 1L

  result$valid <-
    length(result$lambda) == 1L &&
    is.finite(result$lambda) &&
    result$lambda > 0 &&
    lambda_error <= BL_LAMBDA_TOLERANCE &&
    result$native_valid

  if (!result$valid) {
    stop("BL FIXED-lambda contract failed for ", run_id)
  }
  if (lambda_update_warning_count > 0L) {
    stop(
      "Unexpected lambda-update warning under BL type=FIXED for ",
      run_id
    )
  }

  result
}

8.4 Fit one combination

The fitting helper prepares the masked phenotype vector, fits the requested BGLR model, captures warnings, and returns the information needed for the subsequent calculations.

fit_one_run <- function(run_index) {
  trait_name <- run_design$Trait[run_index]
  fold_number <- run_design$Fold[run_index]
  method_name <- run_design$Method[run_index]
  run_id <- run_design$Run_id[run_index]
  run_seed <- run_design$Seed[run_index]

  bglr_run_dir <- file.path(
    BGLR_DIR,
    trait_name,
    paste0("F", fold_number),
    method_name
  )
  dir.create(bglr_run_dir, recursive = TRUE, showWarnings = FALSE)

  save_prefix <- file.path(bglr_run_dir, "bglr_")
  unlink(Sys.glob(paste0(save_prefix, "*")))

  y_observed <- phenotypes[, trait_name]
  names(y_observed) <- ids

  validation_index <- which(cv_folds$Fold == fold_number)
  training_index <- which(cv_folds$Fold != fold_number)

  y_model <- y_observed
  y_model[validation_index] <- NA_real_

  set.seed(run_seed)
  run_warning_messages <- character(0)
  fit_start <- proc.time()[["elapsed"]]

  fit <- withCallingHandlers(
    BGLR::BGLR(
      y = y_model,
      ETA = ETA_models[[method_name]],
      response_type = "gaussian",
      nIter = N_ITER,
      burnIn = BURN_IN,
      thin = THIN,
      R2 = R2_PRIOR,
      saveAt = save_prefix,
      verbose = FALSE,
      rmExistingFiles = TRUE
    ),
    warning = function(w) {
      run_warning_messages <<- c(
        run_warning_messages,
        conditionMessage(w)
      )
      invokeRestart("muffleWarning")
    }
  )

  fit_end <- proc.time()[["elapsed"]]

  tau2_warning_count <- sum(grepl(
    "tau2 was not updated",
    run_warning_messages,
    fixed = TRUE
  ))
  lambda_update_warning_count <- sum(grepl(
    "lambda was not updated",
    run_warning_messages,
    fixed = TRUE
  ))

  bl <- validate_fixed_bl(
    fit = fit,
    save_prefix = save_prefix,
    run_id = run_id,
    method_name = method_name,
    lambda_update_warning_count = lambda_update_warning_count
  )

  list(
    fit = fit,
    trait = trait_name,
    fold = fold_number,
    method = method_name,
    run_id = run_id,
    seed = run_seed,
    save_prefix = save_prefix,
    training_index = training_index,
    validation_index = validation_index,
    y_observed = y_observed,
    warning_messages = run_warning_messages,
    tau2_warning_count = tau2_warning_count,
    lambda_update_warning_count = lambda_update_warning_count,
    bl = bl,
    elapsed_seconds = fit_end - fit_start
  )
}

8.5 OOF predictions and genomic values

For each fitted model,

\[ \widehat y_i = \widehat\mu+ \mathbf x_{Fi}'\widehat{\boldsymbol\beta}_F+ \widehat g_i. \]

Therefore the genomic value is recovered as

\[ \widehat g_i= \widehat y_i- \widehat\mu- \mathbf x_{Fi}'\widehat{\boldsymbol\beta}_F. \]

extract_prediction_outputs <- function(run) {
  fit <- run$fit

  fixed_component <- as.vector(
    X_fixed %*% fit$ETA$fixed$b
  )
  genomic_component <- as.vector(
    fit$yHat - fit$mu - fixed_component
  )

  genomic_values <- data.frame(
    Run_id = run$run_id,
    IND = ids,
    Trait = run$trait,
    Fold = run$fold,
    Method = run$method,
    Genomic_value = genomic_component
  )

    Run_id = run$run_id,

8.6 Predictive and fit metrics

Metrics are calculated separately within each trait-fold-method fit. The OOF correlation, RMSE, MAE, bias, and calibration slope quantify prediction; DIC and the effective number of parameters summarize Bayesian model fit and complexity.

extract_metric_output <- function(run) {
  fit <- run$fit
  observed <- run$y_observed[run$validation_index]
  predicted <- fit$yHat[run$validation_index]

  posterior_prob_in <- c(
    fit$ETA$genomic$probIn,
    NA_real_
  )[1]

  metric <- data.frame(
    Run_id = run$run_id,
    Trait = run$trait,
    Fold = run$fold,
    Method = run$method,
    Seed = run$seed,
    Training_n = length(run$training_index),
    Validation_n = length(run$validation_index),
    Correlation = cor(observed, predicted),
    RMSE = sqrt(mean((observed - predicted)^2)),
    MAE = mean(abs(observed - predicted)),
    Prediction_bias = mean(predicted - observed),
    Regression_slope = cov(observed, predicted) / var(predicted),
    DIC = fit$fit$DIC,
    Effective_parameters = fit$fit$pD,
    Log_likelihood_at_posterior_mean = fit$fit$logLikAtPostMean,
    Posterior_mean = fit$mu,
    Posterior_mean_SD = c(fit$SD.mu, NA_real_)[1],
    Residual_variance = fit$varE,
    Residual_variance_SD = c(fit$SD.varE, NA_real_)[1],
    BL_lambda = run$bl$lambda,
    BL_lambda_native_value = run$bl$native_value,
    BL_lambda_native_serialization_error = run$bl$serialization_error,
    BL_lambda_native_valid = run$bl$native_valid,
    BL_lambda_valid = run$bl$valid,
    BGLR_warning_count = length(run$warning_messages),
    Tau2_warning_count = run$tau2_warning_count,
    Lambda_update_warning_count = run$lambda_update_warning_count,
    Posterior_probIn = posterior_prob_in,
    Elapsed_seconds = run$elapsed_seconds,
    Finite_predictions = all(is.finite(predicted))
  )

  finite_columns <- c(
    "Correlation", "RMSE", "MAE", "Prediction_bias",
    "Regression_slope", "DIC", "Effective_parameters",
    "Log_likelihood_at_posterior_mean", "Posterior_mean",
    "Residual_variance", "Elapsed_seconds"
  )

    is.finite(as.numeric(metric[, finite_columns]))

}

After burn-in is removed from the saved chains, effective sample size (ESS) and the Geweke statistic are calculated with coda.

extract_convergence_output <- function(run) {
  residual_trace_full <- scan(
    paste0(run$save_prefix, "varE.dat"),
    quiet = TRUE
  )

  genomic_trace_table <- read.table(
    paste0(
      run$save_prefix,
      genomic_trace_suffix[run$method]
    ),
    header = genomic_trace_header[run$method],
    check.names = FALSE
  )

  genomic_trace_full <- genomic_trace_table[
    ,
    genomic_trace_column[run$method]
  ]

  posterior_index <- seq.int(
    BURN_IN_SAVED_SAMPLES + 1L,
    length(residual_trace_full)
  )

  trace_matrix <- cbind(
    Residual_variance = residual_trace_full[posterior_index],
    Genomic_parameter = genomic_trace_full[posterior_index]
  )

  trace_object <- coda::mcmc(
    trace_matrix,
    start = BURN_IN + THIN,
    thin = THIN
  )

  trace_ess <- coda::effectiveSize(trace_object)
  trace_geweke <- coda::geweke.diag(trace_object)$z

  parameter_names <- c(
    "Residual_variance",
    unname(genomic_trace_parameter[run$method])
  )

  convergence <- data.frame(
    Run_id = run$run_id,
    Trait = run$trait,
    Fold = run$fold,
    Method = run$method,
    Parameter = parameter_names,
    Retained_samples = nrow(trace_matrix),
    Posterior_mean = colMeans(trace_matrix),
    Posterior_SD = apply(trace_matrix, 2, sd),
    Effective_sample_size = as.numeric(trace_ess),
    Geweke_Z = as.numeric(trace_geweke)
  )

  convergence$Review_flag <-
    !is.finite(convergence$Effective_sample_size) |
    convergence$Effective_sample_size < ESS_REVIEW_THRESHOLD |
    !is.finite(convergence$Geweke_Z) |
    abs(convergence$Geweke_Z) > GEWEKE_REVIEW_THRESHOLD

  convergence
}

A Review_flag therefore indicates a chain requiring inspection. It is not an automatic model-rejection rule and does not by itself prove non-convergence.

13. Summary and next step

Module 03 fits the same statistical structure across seven genomic methods, using family as a fixed effect and the same five OOF folds for every comparison. The distinction between model = "FIXED" for family and type = "FIXED" for the Bayesian-Lasso lambda is explicit, and the fixed lambda is derived from the BGLR calibration rather than from predictive performance.

Module 04 reads models_object.rds without refitting the 350 models. It pools OOF predictions, compares predictive performance and DIC, reviews MCMC stability, and derives trait-specific genomic results.
