Construction of matrices for genomic selection in papaya

Costa, W. G.1

2026-08-25

1. Objective

In this module, the preprocessed SSR genotypes are converted into allele dosages. These dosages are used to construct the centered marker matrix M, the additive genomic relationship matrix G, and the fixed-effect matrix X, which contains family in addition to the intercept. Five family-stratified cross-validation folds are also defined.

The matrices are constructed once using all 150 individuals and remain unchanged across folds. In Module 03, only the phenotype vector is masked to form training and validation sets.

Because candidates in every fold are already genotyped, marker filtering, allele frequencies, mean imputation, M, and G are defined from the full genotype panel and then held fixed. No validation phenotype enters these steps. This corresponds to a transductive candidate-genotype setting and should not be interpreted as external validation in a new genotype population.

The next step loads the preprocessing object and fixes the parameters used to construct the matrices and cross-validation design.

Five folds are used because, with 150 individuals, 5-fold partitioning gives 30 validation individuals and 120 training individuals per fold while preserving family stratification. Each individual appears exactly once in validation; this is one family-stratified five-fold partition, not repeated cross-validation. SEED_CV = 20260723 only reproduces the same allocation of individuals and has no inferential interpretation.

ALLELE_FREQUENCY_MIN = 0.05 retains allele-dosage columns with frequencies between 0.05 and 0.95 provided that dosage variance is also positive. Thus, very rare or nearly fixed alleles do not enter M. The call-rate threshold is inherited from Module 01 to record the same quality-control rule; loci reach this module after that decision has already been applied.

3. Allele-dosage coding

Each SSR code contains two allele labels. For example, 12 represents one copy of allele 1 and one copy of allele 2, whereas 22 represents two copies of allele 2. One dosage column is created for every observed allele at each retained locus.

# Organize marker information and compute the diagnostics required at this stage.
retained_loci_full <- locus_audit_full$Locus[
  locus_audit_full$Keep_locus
]

ssr_full <- ssr_raw[
  ,
  retained_loci_full,
  drop = FALSE
]

dosage_parts_full <- list()
allele_map_parts_full <- list()
marker_counter_full <- 0L

for (j in seq_len(ncol(ssr_full))) {
  # Separate the two alleles encoded in each SSR genotype.
  codes <- ssr_full[, j]
  allele_1 <- floor(codes / 10)
  allele_2 <- codes %% 10

  # List the alleles observed at the current locus.
  observed_alleles <- sort(
    unique(
      c(
        allele_1[!is.na(codes)],
        allele_2[!is.na(codes)]
      )
    )
  )

  for (allele in observed_alleles) {
    marker_counter_full <- marker_counter_full + 1L

    # Count 0, 1, or 2 copies of the allele for each individual.
    dosage <-
      as.numeric(allele_1 == allele) +
      as.numeric(allele_2 == allele)
    dosage[is.na(codes)] <- NA_real_

    # Create a unique identifier for each locus-allele combination.
    marker_name <- paste0(
      colnames(ssr_full)[j],
      "__A",
      allele
    )

    dosage_parts_full[[marker_counter_full]] <- dosage
    allele_map_parts_full[[marker_counter_full]] <- data.frame(
      Locus = colnames(ssr_full)[j],
      Allele = allele,
      Marker = marker_name
    )
  }
}

dosage_full_raw <- do.call(cbind, dosage_parts_full)
allele_audit_full <- bind_rows(allele_map_parts_full)

rownames(dosage_full_raw) <- ids
colnames(dosage_full_raw) <- allele_audit_full$Marker

4. Allele frequencies and retention of dosage columns

Very rare allele columns provide little information in a small sample. Alleles with frequencies between 0.05 and 0.95 and nonzero dosage variation are retained.

# Compute dosage frequency and variability to retain informative allele columns.
allele_audit_full$Allele_frequency <-
  colMeans(dosage_full_raw, na.rm = TRUE) / 2

dosage_sd_full <- numeric(ncol(dosage_full_raw))

for (j in seq_len(ncol(dosage_full_raw))) {
  dosage_sd_full[j] <- sd(
    dosage_full_raw[, j],
    na.rm = TRUE
  )
}

allele_audit_full$Dosage_sd <- dosage_sd_full

allele_audit_full$Keep_allele <-
  is.finite(allele_audit_full$Allele_frequency) &

5. Marker matrix

Missing dosages are replaced by the mean of the corresponding column. Each column is then centered by subtracting its mean. The resulting matrix is denoted by \(\mathbf M\).

# Impute missing dosages by column means, center the columns, and construct marker matrix M.
marker_means_full <- colMeans(
  dosage_full,
  na.rm = TRUE
)

dosage_full_imputed <- dosage_full

for (j in seq_len(ncol(dosage_full_imputed))) {
  # Locate missing dosages in the current column.
  missing_values <- is.na(dosage_full_imputed[, j])

  # Impute the column mean.
  dosage_full_imputed[
    missing_values,
    j
  ] <- marker_means_full[j]
}

# Center every dosage column.
M_full <- sweep(
  dosage_full_imputed,
  2,
  marker_means_full,
  FUN = "-"
)

6. Genomic relationship matrix

Let \(p_j\) be the allele frequency represented by column \(j\). Using a VanRaden-type allele-frequency scaling (VanRaden 2008), the additive genomic relationship matrix is calculated as

\[ \mathbf G = \frac{\mathbf M\mathbf M^{\mathsf T}} {\sum_j 2p_j(1-p_j)}. \]

allele_frequencies_full <- marker_means_full / 2

denominator_full <- sum(
  2 *
    allele_frequencies_full *
    (1 - allele_frequencies_full)
)

G_full <- tcrossprod(M_full) / denominator_full

# Remove only numerical asymmetry.
G_full <- (G_full + t(G_full)) / 2

dimnames(G_full) <- list(ids, ids)

eigenvalues_G_full <- eigen(
  G_full,
  symmetric = TRUE,
  only.values = TRUE
)$values

8. Five family-stratified folds

Family stratification targets prediction among individuals from the represented breeding population. It is not a leave-family-out design and therefore does not estimate predictive performance for entirely new families.

The 150 individuals are divided into five validation groups. Individuals from each family are distributed evenly across folds, and a fixed seed preserves the same allocation across executions.

# Build or summarize the cross-validation fold structure.
set.seed(SEED_CV)

family <- droplevels(metadata$FAM)
folds <- integer(length(ids))
fold_load <- integer(N_FOLDS)

for (family_level in levels(family)) {
  # Randomize the individuals of the current family.
  family_indices <- sample(
    which(family == family_level)
  )

  # Define a random order to break ties between equally loaded folds.
  random_tie_order <- sample(seq_len(N_FOLDS))

  ordered_folds <- order(
    fold_load,
    match(seq_len(N_FOLDS), random_tie_order)
  )

  # Distribute family members across the five folds.
  family_labels <- rep(
    ordered_folds,
    length.out = length(family_indices)
  )

  folds[family_indices] <- family_labels

  fold_load <- fold_load + tabulate(
    family_labels,
    nbins = N_FOLDS
  )
}

fold_sizes <- tabulate(folds, nbins = N_FOLDS)

family_fold_table <- table(
  Family = family,
  Fold = folds
)

# Quantify, within each family, the largest difference in individual counts across folds.
family_balance <- apply(family_fold_table, 1, max) -
  apply(family_fold_table, 1, min)

cv_folds <- data.frame(
  IND = ids,

11. Diagnostics of the constructed matrices

All observed allele columns are retained to preserve a symmetric multiallelic representation. Because dosage columns within a locus are linearly dependent, individual allele coefficients are not interpreted in isolation; later modules focus on predictions and genomic values.

Dependencies among allele columns from the same locus mean that the 72 dosage columns do not represent 72 independent dimensions. The summary below shows dimensions, ranks, and numerical properties of the matrices obtained.
