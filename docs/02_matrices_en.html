The hidden chunk below defines only the rendering options shared by this page. It does not load analytical objects, construct matrices, or affect cross-validation.

1. Objective

In this module, the preprocessed SSR genotypes are converted into allele dosages. These dosages are used to construct the centered marker matrix M, the additive genomic relationship matrix G, and the fixed-effect matrix X, which contains family in addition to the intercept. Five family-stratified cross-validation folds are also defined.

The matrices are constructed once using all 150 individuals and remain unchanged across folds. In Module 03, only the phenotype vector is masked to form training and validation sets.

Because candidates in every fold are already genotyped, marker filtering, allele frequencies, mean imputation, M, and G are defined from the full genotype panel and then held fixed. No validation phenotype enters these steps. This corresponds to a transductive candidate-genotype setting and should not be interpreted as external validation in a new genotype population.

At the end of the module, the reader will have four components used directly in Module 03: the fixed-effect matrix X, the centered marker matrix M, the genomic relationship matrix G, and the cv_folds table identifying each individual’s validation fold. Diagnostics throughout the page check whether allele coding, centering, genomic relationships, and family stratification are coherent with this design.

3. Allele-dosage coding

Each SSR code contains two allele labels. For example, 12 represents one copy of allele 1 and one copy of allele 2, whereas 22 represents two copies of allele 2. For every observed allele at each retained locus, an individual’s dosage is computed as the sum of two indicator functions, one for each allele position in the genotype. The resulting value is 0, 1, or 2 according to whether the individual carries zero, one, or two copies of that allele.

One column is created for every locus–allele combination, and missing SSR calls remain NA until imputation. Before any allele-column filtering, dosages across all alleles at a diploid locus sum to 2 for every observed genotype. This property is later used as a coding diagnostic.

# Organize marker information and compute the diagnostics required at this stage.
retained_loci_full <- locus_audit_full$Locus[
  locus_audit_full$Keep_locus
]

ssr_full <- ssr_raw[
  ,
  retained_loci_full,
  drop = FALSE
]

for (j in seq_len(ncol(ssr_full))) {
  # Separate the two alleles encoded in each SSR genotype.
  codes <- ssr_full[, j]
  allele_1 <- floor(codes / 10)
  allele_2 <- codes %% 10

  # List the alleles observed at the current locus.
  observed_alleles <- sort(
    unique(
      c(
        allele_1[!is.na(codes)],
        allele_2[!is.na(codes)]
      )
    )
  )

  for (allele in observed_alleles) {
    marker_counter_full <- marker_counter_full + 1L

    # Count 0, 1, or 2 copies of the allele for each individual.

      as.numeric(allele_1 == allele) +
      as.numeric(allele_2 == allele)
    dosage[is.na(codes)] <- NA_real_

      colnames(ssr_full)[j],
      "__A",
      allele

    allele_map_parts_full[[marker_counter_full]] <- data.frame(
      Locus = colnames(ssr_full)[j],
      Allele = allele,
      Marker = marker_name
    )
  }
}

4. Allele frequencies and retention of dosage columns

The frequency of an allele column is computed as the mean observed dosage divided by 2 because each diploid individual can contribute two copies of the allele. NA values are ignored here, so the frequency uses available genotype calls only.

Columns are retained when frequency lies between 0.05 and 0.95 and dosage standard deviation is positive. The lower and upper limits are symmetric: they remove very rare alleles and nearly fixed columns, while Dosage_sd > 0 guarantees observed variation. The filter acts on allele-dosage columns; it does not remove individuals.

# Compute dosage frequency and variability to retain informative allele columns.
allele_audit_full$Allele_frequency <-
  colMeans(dosage_full_raw, na.rm = TRUE) / 2

dosage_sd_full <- numeric(ncol(dosage_full_raw))

for (j in seq_len(ncol(dosage_full_raw))) {
  dosage_sd_full[j] <- sd(
    dosage_full_raw[, j],
    na.rm = TRUE
  )
}

allele_audit_full$Dosage_sd <- dosage_sd_full

allele_audit_full$Keep_allele <-
  is.finite(allele_audit_full$Allele_frequency) &
  allele_audit_full$Allele_frequency >= ALLELE_FREQUENCY_MIN &
  allele_audit_full$Allele_frequency <= (1 - ALLELE_FREQUENCY_MIN) &
  is.finite(allele_audit_full$Dosage_sd) &
  allele_audit_full$Dosage_sd > 0

# Select allele columns that pass the frequency and dosage-variation filters.

5. Marker matrix

Missing dosages are replaced by the mean of the corresponding column computed from the full genotype panel. Because the same mean is subtracted during centering, a mean-imputed dosage becomes exactly zero in M: it represents no deviation from the column average rather than a new genotype class.

The resulting matrix is denoted by \(\mathbf M\). Its columns are centered but are not standardized to unit variance. As defined in the objective, imputation uses genotype information from all 150 candidates; no validation phenotype enters this calculation.

# Impute missing dosages by column means, center the columns, and construct marker matrix M.
marker_means_full <- colMeans(
  dosage_full,
  na.rm = TRUE
)

dosage_full_imputed <- dosage_full

for (j in seq_len(ncol(dosage_full_imputed))) {
  # Locate missing dosages in the current column.
  missing_values <- is.na(dosage_full_imputed[, j])

  # Impute the column mean.
  dosage_full_imputed[
    missing_values,
    j
  ] <- marker_means_full[j]
}

# Center every dosage column.
M_full <- sweep(
  dosage_full_imputed,
  2,
  marker_means_full,
  FUN = "-"
)

The summary of M checks four basic properties. Its row count should match the 150 candidates; its column count is the number of retained allele-dosage columns; its rank reveals linear dependencies among columns; and the maximum absolute column mean should be close to zero, confirming numerical centering.

6. Genomic relationship matrix

Let \(p_j\) be the allele frequency represented by column \(j\). Using a VanRaden-type allele-frequency scaling (VanRaden 2008), the additive genomic relationship matrix is calculated as

\[ \mathbf G = \frac{\mathbf M\mathbf M^{\mathsf T}} {\sum_j 2p_j(1-p_j)}. \]

# Recover p_j from the dosage mean, which equals 2p_j.
allele_frequencies_full <- marker_means_full / 2

# Compute the VanRaden scaling from allele-column frequencies.
denominator_full <- sum(
  2 *
    allele_frequencies_full *
    (1 - allele_frequencies_full)
)

# Convert cross-products of centered dosages into scaled genomic relationships.
G_full <- tcrossprod(M_full) / denominator_full

# Remove only numerical asymmetry.
G_full <- (G_full + t(G_full)) / 2

dimnames(G_full) <- list(ids, ids)

eigenvalues_G_full <- eigen(
  G_full,
  symmetric = TRUE,
  only.values = TRUE
)$values

The denominator reports the scale used to construct G. The mean diagonal summarizes each individual’s relationship with itself on this scale and is not forced to equal exactly 1. The symmetry difference should be close to zero. Because G is built from a cross-product, it is theoretically positive semidefinite; therefore, a slightly negative smallest eigenvalue, when limited to numerical precision, should be interpreted as rounding rather than evidence of negative relatedness.

Family is the only categorical fixed effect. With ~ FAM, model.matrix() uses R’s default treatment contrasts: it creates an intercept and enough indicator columns to represent differences among family levels relative to a reference category. 8. Five family-stratified folds

Family stratification targets prediction among individuals from the represented breeding population. It is not a leave-family-out design and therefore does not estimate predictive performance for entirely new families.

The 150 individuals are divided into five validation groups of 30 individuals. The algorithm processes one family at a time: it shuffles family members, orders folds by their current total load, uses a random order only to break ties between equally loaded folds, cycles family members across those folds, and then updates the global load. This combines two goals: spreading each family across folds and keeping total fold sizes balanced.

The fixed seed preserves exactly the same partition across executions. The same fold table is used for all ten traits and all methods, so differences among models cannot arise from different validation partitions.

# Initialize the stratified partition and track each fold's accumulated total load.
set.seed(SEED_CV)

family <- droplevels(metadata$FAM)
folds <- integer(length(ids))
fold_load <- integer(N_FOLDS)

for (family_level in levels(family)) {
  # Randomize the individuals of the current family.
  family_indices <- sample(
    which(family == family_level)
  )

  # Define a random order to break ties between equally loaded folds.
  random_tie_order <- sample(seq_len(N_FOLDS))

  ordered_folds <- order(
    fold_load,
    match(seq_len(N_FOLDS), random_tie_order)
  )

  # Distribute family members across the five folds.
  family_labels <- rep(
    ordered_folds,
    length.out = length(family_indices)
  )

  folds[family_indices] <- family_labels

  fold_load <- fold_load + tabulate(
    family_labels,
    nbins = N_FOLDS
  )
}

fold_sizes <- tabulate(folds, nbins = N_FOLDS)

family_fold_table <- table(
  Family = family,
  Fold = folds
)

# Quantify, within each family, the largest difference in individual counts across folds.
family_balance <- apply(family_fold_table, 1, max) -
  apply(family_fold_table, 1, min)

9. Using the folds for model fitting

The cv_folds table identifies which individuals are masked in each validation round. For fold k, the 30 individuals with Fold == k have their phenotypes replaced by NA, while the other 120 provide training phenotypes. This procedure is repeated for every trait and method.

X, M, and G remain fixed and include all 150 genotyped candidates, consistent with the transductive design defined at the start of the module. Consequently, every individual receives a prediction when its own phenotype is masked, producing an out-of-fold prediction downstream; this is not equivalent to predicting an external genotype population.

11. Diagnostics of the constructed matrices

All allele columns satisfying the declared filters are retained; no category is artificially discarded merely to force full rank. When all alleles at a locus remain represented, their dosages sum to 2 in each diploid individual and an exact linear dependency exists among those columns. Individual allele coefficients are therefore not interpreted in isolation; later modules focus on predictions and genomic values.

In the canonical dataset, the 72 dosage columns do not represent 72 independent dimensions. The diagnostic compares the observed rank of M with sum(k_l - 1), where k_l is the number of retained allele columns at locus l; it also checks whether within-locus dosage still sums to 2, whether M is numerically centered, and whether G can be reconstructed from M and the same denominator. Symmetry, rank, diagonal, and smallest eigenvalue complete the numerical check of G.

# Check dimensions, ranks, linear dependencies, and numerical properties of X, M, and G.

)
