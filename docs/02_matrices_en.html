Construction of matrices for genomic selection in papaya

Costa, W. G.1

2026-08-27

1. Objective

In this module, the preprocessed SSR genotypes are converted into allele dosages. These dosages are used to construct the centered marker matrix M, the additive genomic relationship matrix G, and the fixed-effect matrix X, which contains family in addition to the intercept. Five family-stratified cross-validation folds are also defined.

The matrices are constructed once using all 150 individuals and remain unchanged across folds. In Module 03, only the phenotype vector is masked to form training and validation sets.

Because candidates in every fold are already genotyped, marker filtering, allele frequencies, mean imputation, M, and G are defined from the full genotype panel and then held fixed. No validation phenotype enters these steps. This corresponds to a transductive candidate-genotype setting and should not be interpreted as external validation in a new genotype population.

The module produces four components used directly in Module 03: the fixed-effect matrix X, the centered marker matrix M, the genomic relationship matrix G, and the cv_folds table identifying each individual’s validation fold. The diagnostics check allele coding, centering, genomic relationships, and family stratification.

The preprocessing_object.rds file produced in Module 01 supplies the individuals, phenotypes, families, and SSR loci used to construct the matrices.

Three parameters are defined in this module:

  • N_FOLDS = 5: divides the 150 individuals into five validation groups of 30 individuals, leaving 120 training individuals per fold. Each individual appears in validation exactly once; this is not repeated cross-validation.
  • SEED_CV = 20260723: reproduces exactly the same family-stratified allocation across folds. The seed controls partition reproducibility only and has no inferential interpretation.

3. Allele-dosage coding

Each SSR code contains two allele labels. For example, 12 represents one copy of allele 1 and one copy of allele 2, whereas 22 represents two copies of allele 2. For every observed allele at each retained locus, an individual’s dosage is computed as the sum of two indicator functions, one for each allele position in the genotype. The resulting value is 0, 1, or 2 according to whether the individual carries zero, one, or two copies of that allele.

One column is created for every locus–allele combination, and missing SSR calls remain NA until imputation. Before any allele-column filtering, dosages across all alleles at a diploid locus sum to 2 for every observed genotype. This property is later used as a coding diagnostic.

The coding follows a sequence that maps directly to the operations in the code:

  1. Select retained loci. locus_audit_full$Locus[locus_audit_full$Keep_locus] uses the logical vector Keep_locus to recover only locus names that passed quality control. Then ssr_raw[, retained_loci_full, drop = FALSE] keeps every row and only those columns; drop = FALSE preserves a two-dimensional structure even when few columns are selected.
  2. Separate the two alleles in an SSR code. For a code such as 12, floor(codes / 10) returns the tens digit, the first allele (1). The %% operator returns the remainder of integer division, so codes %% 10 returns the units digit, the second allele (2).
  3. Count copies of each allele. The comparisons allele_1 == allele and allele_2 == allele indicate whether the allele occurs in each position. as.numeric() converts TRUE to 1 and FALSE to 0; summing both positions yields dosage 0, 1, or 2. If the SSR code is missing, dosage remains NA.
  4. Assemble the matrix. Each dosage vector is stored in a list. At the end, do.call(cbind, dosage_parts_full) combines these vectors as columns of one matrix, while bind_rows(allele_map_parts_full) combines the metadata linking each column to its source locus and allele.
# Organize marker information and compute the diagnostics required at this stage.
retained_loci_full <- locus_audit_full$Locus[
  locus_audit_full$Keep_locus
]

ssr_full <- ssr_raw[
  ,
  retained_loci_full,
  drop = FALSE
]

dosage_parts_full <- list()
allele_map_parts_full <- list()
marker_counter_full <- 0L

for (j in seq_len(ncol(ssr_full))) {
  # Separate the two alleles encoded in each SSR genotype.
  codes <- ssr_full[, j]
  allele_1 <- floor(codes / 10)
  allele_2 <- codes %% 10

  # List the alleles observed at the current locus.
  observed_alleles <- sort(
    unique(
      c(
        allele_1[!is.na(codes)],
        allele_2[!is.na(codes)]
      )
    )
  )

  for (allele in observed_alleles) {
    marker_counter_full <- marker_counter_full + 1L

    # Count 0, 1, or 2 copies of the allele for each individual.
    dosage <-
      as.numeric(allele_1 == allele) +
      as.numeric(allele_2 == allele)
    dosage[is.na(codes)] <- NA_real_

    # Create a unique identifier for each locus-allele combination.
    marker_name <- paste0(
      colnames(ssr_full)[j],
      "__A",
      allele
    )

    dosage_parts_full[[marker_counter_full]] <- dosage
    allele_map_parts_full[[marker_counter_full]] <- data.frame(
      Locus = colnames(ssr_full)[j],
      Allele = allele,
      Marker = marker_name
    )
  }
}

dosage_full_raw <- do.call(cbind, dosage_parts_full)
allele_audit_full <- bind_rows(allele_map_parts_full)

rownames(dosage_full_raw) <- ids
colnames(dosage_full_raw) <- allele_audit_full$Marker

4. Allele frequencies and retention of dosage columns

The frequency of an allele column is computed as the mean observed dosage divided by 2 because each diploid individual can contribute two copies of the allele. NA values are ignored here, so the frequency uses available genotype calls only.

Columns are retained when frequency lies between 0.05 and 0.95 and dosage standard deviation is positive. The lower and upper limits are symmetric: they remove very rare alleles and nearly fixed columns, while Dosage_sd > 0 guarantees observed variation. The filter acts on allele-dosage columns; it does not remove individuals.

In the code, colMeans(dosage_full_raw, na.rm = TRUE) / 2 computes frequencies for all columns at once: na.rm = TRUE excludes missing calls from the mean, and division by 2 converts mean dosage, which ranges from 0 to 2, into allele frequency between 0 and 1. The loop with sd(..., na.rm = TRUE) computes the standard deviation of each column. Finally, is.finite() prevents non-finite results from being accepted before the frequency limits and Dosage_sd > 0 condition are applied.

# Compute dosage frequency and variability to retain informative allele columns.
allele_audit_full$Allele_frequency <-
  colMeans(dosage_full_raw, na.rm = TRUE) / 2

dosage_sd_full <- numeric(ncol(dosage_full_raw))

for (j in seq_len(ncol(dosage_full_raw))) {
  dosage_sd_full[j] <- sd(
    dosage_full_raw[, j],
    na.rm = TRUE
  )
}

allele_audit_full$Dosage_sd <- dosage_sd_full

allele_audit_full$Keep_allele <-
  is.finite(allele_audit_full$Allele_frequency) &
  allele_audit_full$Allele_frequency >= ALLELE_FREQUENCY_MIN &
  allele_audit_full$Allele_frequency <= (1 - ALLELE_FREQUENCY_MIN) &
  is.finite(allele_audit_full$Dosage_sd) &
  allele_audit_full$Dosage_sd > 0

# Select allele columns that pass the frequency and dosage-variation filters.

5. Marker matrix

Missing dosages are replaced by the mean of the corresponding column computed from the full genotype panel. marker_means_full <- colMeans(dosage_full, na.rm = TRUE) computes one mean per column. Inside the loop, is.na(dosage_full_imputed[, j]) identifies missing positions in column j, which receive marker_means_full[j].

After imputation, sweep(dosage_full_imputed, 2, marker_means_full, FUN = "-") centers the dosages. The argument 2 specifies a column-wise operation, and FUN = "-" subtracts the corresponding mean from every value. Because the same mean was used for imputation, a mean-imputed dosage becomes exactly zero in M: it represents no deviation from the column average rather than a new genotype class.

The resulting matrix is denoted by \(\mathbf M\). Its columns are centered but are not standardized to unit variance. Imputation uses genotype information from all 150 candidates; no validation phenotype enters this calculation.

# Impute missing dosages by column means, center the columns, and construct marker matrix M.
marker_means_full <- colMeans(
  dosage_full,
  na.rm = TRUE
)

dosage_full_imputed <- dosage_full

for (j in seq_len(ncol(dosage_full_imputed))) {
  # Locate missing dosages in the current column.
  missing_values <- is.na(dosage_full_imputed[, j])

  # Impute the column mean.
  dosage_full_imputed[
    missing_values,
    j
  ] <- marker_means_full[j]
}

# Center every dosage column.
M_full <- sweep(
  dosage_full_imputed,
  2,
  marker_means_full,
  FUN = "-"
)

6. Genomic relationship matrix

Let \(p_j\) be the allele frequency represented by column \(j\). Using a VanRaden-type allele-frequency scaling (VanRaden 2008), the additive genomic relationship matrix is calculated as

\[ \mathbf G = \frac{\mathbf M\mathbf M^{\mathsf T}} {\sum_j 2p_j(1-p_j)}. \]

In the code, allele_frequencies_full <- marker_means_full / 2 recovers \(p_j\) because mean dosage equals \(2p_j\). tcrossprod(M_full) directly computes \(\mathbf M\mathbf M^{\mathsf T}\), a product among individuals based on the centered columns. Dividing by denominator_full applies the scale defined in the equation. Then (G_full + t(G_full)) / 2 removes only small numerical differences between symmetric elements, and eigen(..., symmetric = TRUE, only.values = TRUE) obtains the eigenvalues used to diagnose positive semidefiniteness.

# Recover p_j from the dosage mean, which equals 2p_j.
allele_frequencies_full <- marker_means_full / 2

# Compute the VanRaden scaling from allele-column frequencies.
denominator_full <- sum(
  2 *
    allele_frequencies_full *
    (1 - allele_frequencies_full)
)

# Convert cross-products of centered dosages into scaled genomic relationships.
G_full <- tcrossprod(M_full) / denominator_full

# Remove only numerical asymmetry.
G_full <- (G_full + t(G_full)) / 2

dimnames(G_full) <- list(ids, ids)

eigenvalues_G_full <- eigen(
  G_full,
  symmetric = TRUE,
  only.values = TRUE
)$values

The denominator reports the scale used to construct G. The mean diagonal summarizes each individual’s relationship with itself on this scale and is not forced to equal exactly 1. The symmetry difference should be close to zero. Because G is built from a cross-product, it is theoretically positive semidefinite; therefore, a slightly negative smallest eigenvalue, when limited to numerical precision, should be interpreted as rounding rather than evidence of negative relatedness.

7. Fixed-effect matrix

Family is the only categorical fixed effect. With ~ FAM, model.matrix() uses R’s default treatment contrasts: it creates an intercept and enough indicator columns to represent differences among family levels relative to a reference category. Thus, X incorporates family structure without treating FAM as a numeric variable.

8. Five family-stratified folds

Family stratification targets prediction among individuals from the represented breeding population. It is not a leave-family-out design and therefore does not estimate predictive performance for entirely new families.

The 150 individuals are divided into five validation groups of 30 individuals. The construction proceeds family by family and can be followed directly through the functions used in the code:

  1. which(family == family_level) locates individuals from the current family, and sample() shuffles their positions.
  2. seq_len(N_FOLDS) generates the five fold numbers. A second sample() call creates a random order used only to break ties among folds with equal accumulated load.
  3. order(fold_load, match(seq_len(N_FOLDS), random_tie_order)) prioritizes less-filled folds first and uses the random order only when two loads are equal.
  4. rep(ordered_folds, length.out = length(family_indices)) cycles through this order until one fold label is produced for every family member.
  5. tabulate(family_labels, nbins = N_FOLDS) counts how many individuals were just assigned to each fold and updates fold_load.

This procedure spreads members of each family across folds while keeping total fold sizes balanced. After allocation, apply(family_fold_table, 1, max) and apply(family_fold_table, 1, min) compute, for each row of the table — that is, for each family — the largest and smallest counts across folds. The argument 1 specifies a row-wise operation; the difference between maximum and minimum forms family_balance.

The fixed seed preserves exactly the same partition across executions. The same fold table is used for all ten traits and all methods, so differences among models cannot arise from different validation partitions.

# Initialize the stratified partition and track each fold's accumulated total load.
set.seed(SEED_CV)

family <- droplevels(metadata$FAM)
folds <- integer(length(ids))
fold_load <- integer(N_FOLDS)

for (family_level in levels(family)) {
  # Randomize the individuals of the current family.
  family_indices <- sample(
    which(family == family_level)
  )

  # Define a random order to break ties between equally loaded folds.
  random_tie_order <- sample(seq_len(N_FOLDS))

  ordered_folds <- order(
    fold_load,
    match(seq_len(N_FOLDS), random_tie_order)
  )

  # Distribute family members across the five folds.
  family_labels <- rep(
    ordered_folds,
    length.out = length(family_indices)
  )

  folds[family_indices] <- family_labels

  fold_load <- fold_load + tabulate(
    family_labels,
    nbins = N_FOLDS
  )
}

fold_sizes <- tabulate(folds, nbins = N_FOLDS)

family_fold_table <- table(
  Family = family,

)

9. Using the folds for model fitting

The cv_folds table identifies which individuals are masked in each validation round. For fold k, the 30 individuals with Fold == k have their phenotypes replaced by NA, while the other 120 provide training phenotypes. This procedure is repeated for every trait and method.

X, M, and G remain fixed and include all 150 genotyped candidates, consistent with the transductive design defined at the start of the module. Consequently, every individual receives a prediction when its own phenotype is masked, producing an out-of-fold prediction downstream; this is not equivalent to predicting an external genotype population.

The expression cv_folds |> arrange(Fold, FAM, IND) |> head(15) sorts the table first by fold, then by family and individual identifier, and retains the first 15 rows. arrange() defines this order and head(15) limits only the displayed preview; the cv_folds object still contains all 150 individuals. The Fold column is the information Module 03 uses to decide which phenotypes are masked in each validation round.

11. Diagnostics of the constructed matrices

All allele columns satisfying the declared filters are retained; no category is artificially discarded merely to force full rank. When all alleles at a locus remain represented, their dosages sum to 2 in each diploid individual and an exact linear dependency exists among those columns. Individual allele coefficients are therefore not interpreted in isolation; later modules focus on predictions and genomic values.

In the analyzed dataset, the 72 dosage columns do not represent 72 independent dimensions. The structural rank bound imposed by within-locus dependencies is computed by sum(table(...) - 1L): table() counts retained allele columns at each locus, subtracting 1 gives \(k_l-1\) for each locus, and sum() combines those contributions. This value is the maximum allowed by the within-locus dependencies when no additional linear dependencies occur across loci; the observed rank of M is then compared with this bound.

The diploid property is checked locus by locus with rowSums(...) - 2: rowSums() adds the retained allele dosages for each individual, and the difference from 2 should be numerically zero. Centering is checked through the column means of M, and tcrossprod(M_full) / denominator_full reconstructs G for comparison with the stored matrix. Symmetry, rank, diagonal, and smallest eigenvalue complete the numerical check of G.
