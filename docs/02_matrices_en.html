Construction of matrices for genomic selection in papaya

Costa, W. G.1

2026-09-09

1. Objective

In this module, the preprocessed SSR genotypes are converted into allele dosages. These dosages are used to construct the centered marker matrix M, the additive genomic relationship matrix G, and the fixed-effect matrix X, which contains family in addition to the intercept. Five family-stratified cross-validation folds are also defined.

The matrices are constructed once using all 150 individuals and remain unchanged across folds. In Module 03, only the phenotype vector is masked to form training and validation sets.

Because candidates in every fold are already genotyped, marker filtering, allele frequencies, mean imputation, M, and G are defined from the full genotype panel and then held fixed. No validation phenotype enters these steps. This corresponds to a transductive candidate-genotype setting and should not be interpreted as external validation in a new genotype population.

The matrix core of the contract delivered to Module 03 consists of four components: the fixed-effect matrix X, the centered marker matrix M, the genomic relationship matrix G, and the cv_folds table identifying each individual’s validation fold. The persisted object also preserves identifiers, metadata, aligned phenotypes, the trait dictionary, and auxiliary diagnostics. The diagnostics check allele coding, centering, genomic relationships, and family stratification.

The functional workflow of the module follows this sequence:

receive the preprocessed object → code allele dosages → filter allele columns → impute and center M → construct G → construct X → define the folds → audit the matrices → export the contract to Module 03.

3. Allele-dosage coding

3.1 From SSR code to allele dosage

Each SSR code contains two allele labels. For example, 12 represents one copy of allele 1 and one copy of allele 2, whereas 22 represents two copies of allele 2. For every observed allele at each retained locus, an individual’s dosage is computed as the sum of two indicator functions, one for each allele position in the genotype. The resulting value is 0, 1, or 2 according to whether the individual carries zero, one, or two copies of that allele.

One column is created for every locus–allele combination, and missing SSR calls remain NA until imputation. Before any allele-column filtering, dosages across all alleles at a diploid locus sum to 2 for every observed genotype. This property is later used as a coding diagnostic.

3.2 Expanding loci into allele columns

Coding proceeds across retained loci, identifies the alleles observed at each locus, and creates one dosage column for every locus–allele combination. To keep this transformation traceable, each combination receives an identifier in the form Locus__Aallele. The same identifier names the dosage column and appears in allele_audit_full, linking the matrix back to its source locus and allele.

The nested traversal below follows that logic directly: it first iterates over loci and, within each locus, over the observed alleles. Missing SSR calls remain NA, and no individual is removed.

4. Quality control of allele-dosage columns

4.1 Allele frequencies and retention criteria

The frequency of an allele column is computed as the mean observed dosage divided by 2 because each diploid individual can contribute two copies of the allele. NA values are ignored here, so the frequency uses available genotype calls only.

Columns are retained when frequency lies between 0.05 and 0.95 and dosage standard deviation is positive. The lower and upper limits are symmetric: they remove very rare alleles and nearly fixed columns, while Dosage_sd > 0 guarantees observed variation. The filter acts on allele-dosage columns; it does not remove individuals.

# Define the frequency threshold immediately before applying it to the allele-column filter.

  colMeans(dosage_full_raw, na.rm = TRUE) / 2

  dosage_full_raw,
  2,

5. Construction of marker matrix M

5.1 Imputation of missing dosages

Missing dosages are imputed with the mean of the corresponding column computed from the full genotype panel. Column means are calculated first. Then which(..., arr.ind = TRUE) identifies the row and column of every missing cell; the column index directly retrieves the mean of the corresponding marker. All missing values therefore follow the same replacement rule without creating a new genotype category and without using phenotype information.

The table compares the matrix before and after imputation, reporting both the total number of missing dosages and the number of columns that still contain at least one missing value.

5.2 Centering and construction of M

After imputation, each column is centered by subtracting exactly the same mean stored in marker_means_full. The resulting matrix is denoted by \(\mathbf M\). Its columns are centered but are not standardized to unit variance.

At positions that were originally missing, the imputed dosage equals its own column mean. Subtracting that same mean therefore makes those positions equal to zero in M. Zero represents no deviation from the column mean rather than a new genotype class. Imputation and centering use genotype information from all 150 candidates; no validation phenotype participates in these operations.

M_full <- sweep(
  dosage_full_imputed,
  2,
  marker_means_full,
  FUN = "-"

6. Construction of genomic relationship matrix G

6.1 Definition and scale of G

Let \(p_j\) be the allele frequency represented by column \(j\). Using a VanRaden-type allele-frequency scaling (VanRaden 2008), the additive genomic relationship matrix is calculated as

\[ \mathbf G = \frac{\mathbf M\mathbf M^{\mathsf T}} {\sum_j 2p_j(1-p_j)}. \]

Because an SSR locus can generate several allele-dosage columns, these columns should not be interpreted as independent markers. When all alleles from the same diploid locus remain represented, their dosages sum to 2 within each individual. After centering, the deviations across those columns sum to zero, creating a structural linear dependence among them.

This dependence does not prevent construction of G. Matrix G does not require inversion of M or separate estimation of an identifiable coefficient for every allele column. Instead, the cross-product M M^T aggregates, for each pair of individuals, the agreement between their allele-dosage deviation profiles. A multiallelic locus therefore contributes to genomic relationship through its set of alleles, while dependence among its columns remains an expected property of the coding.

6.2 Construction of G

Allele frequencies used in the scaling are obtained from dosage means because mean dosage equals \(2p_j\). For each allele column, the term \(2p_j(1-p_j)\) provides a frequency-based variability scale; summing these terms gives a global denominator across all columns. Because M is centered but not standardized column by column, this denominator converts the raw cross-product to a common genomic-relationship scale.

For two individuals, an off-diagonal cell of \(\mathbf M\mathbf M^{\mathsf T}\) is the inner product of their centered dosage profiles. Deviations in the same direction contribute positively, whereas deviations in opposite directions contribute negatively. After division by the denominator, off-diagonal elements of G describe relative genomic relationship between pairs of individuals, using allele frequencies in this panel as the reference. A negative value indicates lower genomic similarity relative to that reference rather than a biologically antagonistic relationship.

On the diagonal, each individual is compared with itself; diagonal elements therefore summarize self-relatedness on the adopted scale. Because the normalization is global and does not force each individual diagonal separately, these values need not equal exactly 1. The resulting matrix is numerically symmetrized before its eigenvalues are evaluated.

# Recover p_j from the dosage mean, which equals 2p_j.
allele_frequencies_full <- marker_means_full / 2

# Compute the VanRaden scaling from allele-column frequencies.
denominator_full <- sum(
  2 *
    allele_frequencies_full *
    (1 - allele_frequencies_full)
)


# Convert cross-products of centered dosages into scaled genomic relationships.
G_full <- tcrossprod(M_full) / denominator_full

# Record numerical asymmetry of the scaled cross-product before rounding correction.
maximum_G_asymmetry_before_symmetrization <- max(
  abs(G_full - t(G_full))
)

# Remove only numerical asymmetry.
G_full <- (G_full + t(G_full)) / 2

dimnames(G_full) <- list(ids, ids)

# Keep only the smallest eigenvalue, which is the diagnostic used downstream.
minimum_eigenvalue_G_full <- min(
  eigen(
    G_full,
    symmetric = TRUE,
    only.values = TRUE
  )$values
)

6.3 Numerical diagnostics of G

The denominator reports the scale used to construct G. The mean diagonal summarizes each individual’s relationship with itself on this scale and is not forced to equal exactly 1. To avoid making the symmetry diagnostic tautological, numerical asymmetry is measured on the scaled cross-product before symmetrization; this value should be close to zero. Because G is built from a cross-product, it is theoretically positive semidefinite; therefore, a slightly negative smallest eigenvalue, when limited to numerical precision, should be interpreted as rounding rather than evidence of negative relatedness.

7.2 Evaluation scenario

Family stratification targets prediction among individuals from the represented breeding population. It is not a leave-family-out design and therefore does not estimate predictive performance for entirely new families.

7.3 Construction of the stratified folds

The 150 individuals are distributed into five validation groups. Allocation proceeds family by family: individuals in the current family are first shuffled; folds are then ordered by their accumulated total load, with a random order used only to break ties between equally loaded folds. Family members are subsequently distributed cyclically along that order. The algorithm therefore combines family representation with balanced total fold sizes.

The fixed seed preserves exactly the same partition across executions. Because the sample() calls are part of the tie-breaking and within-family shuffling rules, their sequence is kept explicit in the code. The same cv_folds table will be used for all ten traits and all methods.

# Define cross-validation parameters immediately before constructing the folds.
N_FOLDS <- 5L
SEED_CV <- 20260723L

set.seed(SEED_CV)

# Initialize each individual's family, fold assignment, and the accumulated fold loads.
family <- droplevels(metadata$FAM)
folds <- integer(length(ids))
fold_load <- integer(N_FOLDS)

for (family_level in levels(family)) {
  # Randomize the individuals of the current family.
  family_indices <- sample(
    which(family == family_level)
  )

  # Draw an order used only to break ties between folds with equal accumulated load.
  random_tie_order <- sample(seq_len(N_FOLDS))

  ordered_folds <- order(
    fold_load,
    match(seq_len(N_FOLDS), random_tie_order)
  )

  # Distribute family members cyclically according to the fold order.
  family_labels <- rep(
    ordered_folds,
    length.out = length(family_indices)
  )

  folds[family_indices] <- family_labels

  # Update total fold loads before processing the next family.
  fold_load <- fold_load + tabulate(
    family_labels,
    nbins = N_FOLDS
  )

8.2 Structural dependence and rank of M

All allele columns satisfying the declared filters are retained; no category is artificially discarded merely to force full rank. When all alleles at a locus remain represented, their dosages sum to 2 in each diploid individual and an exact linear dependency exists among those columns. Individual allele coefficients are therefore not interpreted in isolation; later modules focus on predictions and genomic values.

The 72 dosage columns do not represent 72 independent dimensions. For each locus with \(k_l\) retained allele columns, the diploid constraint allows at most \(k_l-1\) independent directions among those columns. The structural rank bound of M sums these contributions across loci and is compared with the observed rank to determine whether additional linear dependencies occur.

8.3 Consolidated numerical checks

The diploid coding property is checked before allele-column filtering: for every retained SSR locus from Module 01, dosages across all alleles originally coded for an observed genotype must sum to 2. Missing SSR calls are excluded from this check rather than imputed for it.

Reconstruction of G repeats the complete construction from Section 6: the cross-product of M, division by the denominator, and the same numerical symmetrization. The difference between G_full and G_reconstructed therefore checks consistency of the final matrix actually used, whereas maximum_G_asymmetry_before_symmetrization, computed earlier, separately quantifies numerical asymmetry before that correction. The inventory also consolidates centering, dimensions, ranks, fold sizes, the diagonal, and the smallest eigenvalue.
