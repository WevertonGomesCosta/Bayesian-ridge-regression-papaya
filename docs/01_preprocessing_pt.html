Pré-processamento dos dados para seleção genômica em mamoeiro

Costa, W. G.1

2026-08-25

1. Objetivo

A seleção genômica exige que fenótipos e marcadores representem os mesmos indivíduos e estejam organizados na mesma ordem. Neste módulo, as duas fontes de dados são lidas, os identificadores são organizados, os códigos de ausência dos SSR são convertidos em NA, os fenótipos são alinhados aos genótipos e os locos SSR são submetidos ao controle de qualidade.

A coluna de bloco (BL) é removida porque não participa do modelo estatístico. A família (FAM) é mantida para ser utilizada como efeito fixo nos módulos seguintes.

A etapa seguinte define os caminhos dos arquivos usados como entradas e saídas do módulo. Esses caminhos apenas organizam a leitura e a persistência dos resultados e não constituem parâmetros estatísticos.

Dois parâmetros de controle são fixados neste ponto. CALL_RATE_MIN = 0.90 exige que pelo menos 90% das chamadas de um loco estejam disponíveis; em conjunto com a exigência de pelo menos duas classes genotípicas, esse limite evita manter locos com informação insuficiente. PHENOTYPE_DISTANCE_THRESHOLD = 4 identifica, apenas para inspeção, observações a pelo menos quatro desvios-padrão da média da característica. Essa regra é diagnóstica: nenhum fenótipo é removido, winsorizado ou alterado por esse limite.

# Define os dois arquivos de entrada e a pasta em que o pré-processamento será salvo.
GENOTYPE_FILE <- here("data", "papaya_ssr_genotypes.xlsx")
PHENOTYPE_FILE <- here("data", "papaya_phenotypes_2024_2025.xlsx")
OUTPUT_DIR <- here("output", "preprocessing")

# Exige pelo menos 90% de chamadas disponíveis para manter um loco SSR.
CALL_RATE_MIN <- 0.90
# Usa quatro desvios-padrão somente como limiar de sinalização diagnóstica.
PHENOTYPE_DISTANCE_THRESHOLD <- 4

dir.create(OUTPUT_DIR, recursive = TRUE, showWarnings = FALSE)

6. Controle de qualidade dos marcadores

Para cada loco são calculados a taxa de chamada e o número de classes genotípicas observadas. Um loco é mantido quando apresenta taxa de chamada igual ou superior a 0,90 e pelo menos duas classes genotípicas.

# Calcula taxa de chamada e diversidade de classes genotípicas para decidir quais locos SSR serão mantidos.
genotype_classes <- integer(ncol(ssr_raw))

for (j in seq_len(ncol(ssr_raw))) {
  # Conta quantas classes genotípicas foram observadas no loco.
  genotype_classes[j] <- length(
    unique(na.omit(ssr_raw[, j]))
  )
}

locus_audit <- data.frame(
  Locus = colnames(ssr_raw),
  N_called = colSums(!is.na(ssr_raw)),
  Call_rate = colMeans(!is.na(ssr_raw)),
  N_genotype_classes = genotype_classes
)

rownames(locus_audit) <- NULL

locus_audit$Keep_locus <-
  locus_audit$Call_rate >= CALL_RATE_MIN &
  locus_audit$N_genotype_classes >= 2

# Mantém na matriz SSR apenas os locos que passaram os critérios de qualidade.

8.1 Observações fenotípicas distantes da média

Os valores padronizados são utilizados apenas como diagnóstico descritivo. Uma observação é destacada quando sua distância absoluta em relação à média é de pelo menos 4 desvios-padrão. Os valores são mantidos exatamente como registrados na planilha original.

# Padroniza os fenótipos e identifica observações distantes da média segundo o limite definido.
phenotype_means <- colMeans(phenotypes)
phenotype_standard_deviations <- numeric(ncol(phenotypes))

for (j in seq_len(ncol(phenotypes))) {
  phenotype_standard_deviations[j] <- sd(phenotypes[, j])
}

phenotype_standardized <- scale(
  phenotypes,
  center = phenotype_means,
  scale = phenotype_standard_deviations
)

# Localiza as observações cuja distância padronizada alcança o limite definido.
extreme_positions <- which(
  abs(phenotype_standardized) >= PHENOTYPE_DISTANCE_THRESHOLD,
  arr.ind = TRUE
)

phenotype_extremes <- data.frame(
  IND = rownames(phenotypes)[extreme_positions[, "row"]],
  Trait = colnames(phenotypes)[extreme_positions[, "col"]],
  Value = phenotypes[extreme_positions],
  Trait_mean = phenotype_means[extreme_positions[, "col"]],
  Trait_SD = phenotype_standard_deviations[extreme_positions[, "col"]],
  Standardized_value = phenotype_standardized[extreme_positions],
  Absolute_standardized_distance = abs(
    phenotype_standardized[extreme_positions]
  )
)

# Organiza os fenótipos usados na análise.
phenotype_extremes <- phenotype_extremes[
  order(-phenotype_extremes$Absolute_standardized_distance),
]
rownames(phenotype_extremes) <- NULL

9. Gravação dos resultados do pré-processamento

A matriz fenotípica alinhada, os dados SSR, os metadados e os resumos são reunidos em um objeto que será utilizado na construção das matrizes genômicas.

# Reúne os objetos do pré-processamento e grava as saídas usadas no módulo seguinte.
preprocessing_object <- list(
  ids = ids,
  metadata = metadata,
  phenotypes = phenotypes,
  ssr_raw = ssr_raw,
  ssr = ssr,
  locus_audit = locus_audit,
  individual_audit = individual_audit,
  phenotype_summary = phenotype_summary,
  phenotype_extremes = phenotype_extremes,
  trait_dictionary = trait_dictionary,
  # Registra os parâmetros e limites necessários para reproduzir esta etapa.
  settings = list(
    call_rate_min = CALL_RATE_MIN,
    phenotype_distance_threshold = PHENOTYPE_DISTANCE_THRESHOLD,
    fixed_effects = "FAM"

saveRDS(
