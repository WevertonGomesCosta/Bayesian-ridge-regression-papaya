Pré-processamento dos dados para seleção genômica em mamoeiro

Costa, W. G.1

2026-08-25

1. Objetivo

A seleção genômica exige que fenótipos e marcadores representem os mesmos indivíduos e estejam organizados na mesma ordem. Neste módulo, as duas fontes de dados são lidas, os identificadores são organizados, os códigos de ausência dos SSR são convertidos em NA, os fenótipos são alinhados aos genótipos e os locos SSR são submetidos ao controle de qualidade.

A coluna de bloco (BL) é removida porque não participa do modelo estatístico adotado nesta análise. A família (FAM) é preservada porque será utilizada tanto na matriz de efeitos fixos quanto na estratificação dos folds de validação cruzada no Módulo 02. Nenhum indivíduo é removido neste módulo.

O pré-processamento produz três objetos centrais para as etapas seguintes: a matriz fenotípica alinhada, a matriz SSR após o controle de qualidade dos locos e os metadados com indivíduo e família. Os diagnósticos verificam a consistência desses objetos antes da construção das matrizes genômicas.

2. Pacotes, arquivos e parâmetros

Os pacotes utilizados neste módulo têm funções distintas:

  • readxl: leitura das planilhas Excel com os dados genotípicos e fenotípicos;
  • dplyr: seleção, transformação e organização das tabelas;
  • tidyr: reorganização dos dados entre formatos largo e longo;
  • ggplot2: construção dos gráficos de controle de qualidade e distribuição fenotípica;
  • knitr: formatação de tabelas em documentos R Markdown;
  • here: construção de caminhos de arquivos independentes do diretório local do computador.
library(readxl)  # Leitura de arquivos Excel.
library(dplyr)   # Manipulação e transformação de tabelas.
library(tidyr)   # Reorganização de dados entre formatos largo e longo.
library(ggplot2) # Construção de gráficos.
library(knitr)   # Formatação de tabelas e saídas do R Markdown.
library(here)    # Construção de caminhos portáveis dentro do projeto.

Dois parâmetros de controle são fixados:

  • CALL_RATE_MIN = 0.90: exige que pelo menos 90% das chamadas de um loco estejam disponíveis. Como o painel possui 150 indivíduos, isso corresponde a pelo menos 135 genótipos observados por loco. Em conjunto com a exigência de pelo menos duas classes genotípicas, o critério evita manter locos com informação insuficiente para representar variação.
  • PHENOTYPE_DISTANCE_THRESHOLD = 4: identifica, apenas para inspeção, observações a pelo menos quatro desvios-padrão da média da característica. Essa regra é diagnóstica: nenhum fenótipo é removido, limitado a um valor de corte ou alterado por esse critério.
# Define os dois arquivos de entrada e a pasta em que o pré-processamento será salvo.

# Usa quatro desvios-padrão somente como limiar de sinalização diagnóstica.

3. Leitura das planilhas originais

A planilha genotípica utiliza a aba Genes para os códigos numéricos dos marcadores SSR e a aba Genealex para os identificadores dos indivíduos e dos locos. Essas duas abas são lidas sem cabeçalho porque contêm linhas de metadados próprias do formato de origem; a posição dos identificadores será tratada explicitamente na seção seguinte. Os fenótipos são lidos da aba Médias_IND_artigo, que já possui nomes de colunas.

A coluna BL é retirada imediatamente após a leitura dos fenótipos para impedir que o bloco seja propagado para os objetos analíticos. As primeiras linhas permitem reconhecer a organização original dos dados, e a tabela de dimensões verifica a estrutura das três fontes antes do alinhamento.

4. Organização dos dados SSR

A primeira coluna da aba Genes contém um índice sequencial de grupos populacionais e não representa a variável fenotípica FAM; por isso ela é excluída da matriz de marcadores. As 35 colunas restantes correspondem aos locos SSR originais.

Na aba Genealex, a posição de cada informação é definida explicitamente:

  1. Linhas dos indivíduos. Os identificadores começam na linha 4 da segunda coluna. Como existem n_individuals indivíduos, as linhas são definidas por individual_rows <- 4:(3 + n_individuals). O intervalo começa em 4 e termina em 3 + n_individuals, incluindo exatamente uma linha para cada indivíduo.
  2. Colunas dos locos. Os nomes dos locos estão na linha 3 e aparecem em colunas alternadas a partir da coluna 3. Essas posições são obtidas com locus_columns <- seq(3, 2 + 2 * n_loci, by = 2). A função seq() começa em 3 e avança de duas em duas colunas até reunir os n_loci nomes.
  3. Identificadores dos indivíduos. A expressão genealex[[2]][individual_rows] seleciona a segunda coluna apenas nas linhas definidas acima. Em seguida, as.character() preserva identificadores alfanuméricos e trimws() remove espaços antes ou depois do código: ids <- trimws(as.character(genealex[[2]][individual_rows])).
  4. Nomes dos locos. A expressão genealex[3, locus_columns] seleciona a terceira linha somente nas colunas dos locos. unlist(..., use.names = FALSE) transforma essa seleção em um vetor, e trimws(as.character(...)) garante nomes em formato de texto sem espaços externos.
  5. Matriz SSR. A expressão genes[, -1, drop = FALSE] seleciona todas as linhas e exclui a primeira coluna de Genes; o índice -1 significa “todas as colunas, exceto a primeira”. drop = FALSE mantém o resultado como uma estrutura bidimensional. as.matrix() transforma essa seleção em matriz e storage.mode(ssr_raw) <- "numeric" garante armazenamento numérico dos códigos SSR.
  6. Chamadas ausentes. Depois de formar a matriz numérica de SSR, o código ssr_raw[ssr_raw == -9] <- NA_real_ substitui o valor -9, usado no arquivo de origem para indicar ausência, pelo valor ausente padrão do R (NA).
# Obtém as dimensões do painel a partir da aba `Genes`; a primeira coluna não é um loco SSR.
n_individuals <- nrow(genes)
n_loci <- ncol(genes) - 1

# Traduz a estrutura da aba `Genealex`: indivíduos a partir da linha 4 e locos em colunas alternadas.
individual_rows <- 4:(3 + n_individuals)
locus_columns <- seq(3, 2 + 2 * n_loci, by = 2)

# Mantém os identificadores como texto para preservar códigos alfanuméricos.
ids <- trimws(
  as.character(genealex[[2]][individual_rows])
)

locus_names <- trimws(
  as.character(
    unlist(genealex[3, locus_columns], use.names = FALSE)
  )
)

ssr_raw <- as.matrix(
  genes[, -1, drop = FALSE]
)

storage.mode(ssr_raw) <- "numeric"
# Converte o código de ausência do arquivo original para o valor ausente padrão do R.
ssr_raw[ssr_raw == -9] <- NA_real_

rownames(ssr_raw) <- ids
colnames(ssr_raw) <- locus_names

5. Organização e alinhamento dos fenótipos

Dez características são utilizadas. Antes do alinhamento, três verificações evitam associar genótipos e fenótipos incorretamente:

  1. Colunas obrigatórias. required_columns <- c("IND", "FAM", TRAITS) reúne as colunas esperadas. setdiff(required_columns, names(pheno_raw)) retorna quais delas não existem na planilha; quando o resultado é vazio, todas estão presentes.
  2. Indivíduos presentes em apenas uma fonte. setdiff(ids, pheno_raw$IND) identifica genótipos sem fenótipo correspondente, enquanto setdiff(pheno_raw$IND, ids) faz a comparação inversa e identifica fenótipos sem genótipo.
  3. Identificadores inválidos ou repetidos. is.na() e a comparação com "" identificam códigos ausentes ou vazios; duplicated() identifica repetições que impediriam uma correspondência individual inequívoca.

Depois dessas verificações, o alinhamento é feito com match(ids, pheno_raw$IND). Para cada identificador presente em ids, match() retorna a posição correspondente em pheno_raw$IND. Essas posições são usadas diretamente em pheno_raw[match(ids, pheno_raw$IND), required_columns], que reordena as linhas fenotípicas na mesma sequência da matriz SSR. Assim, a linha i dos fenótipos e a linha i dos genótipos passam a representar o mesmo indivíduo.

Após o alinhamento, factor(pheno$FAM) converte FAM em variável categórica, preservando os níveis de família. Já as.matrix(pheno[, TRAITS]) seleciona apenas as dez características e as reúne em uma matriz; storage.mode(phenotypes) <- "numeric" garante que seus valores sejam tratados numericamente nos cálculos posteriores.

6. Controle de qualidade dos marcadores

Para cada loco, a taxa de chamada é calculada por colMeans(!is.na(ssr_raw)). Primeiro, is.na(ssr_raw) identifica as células ausentes; o operador ! inverte o resultado, deixando TRUE para genótipos observados e FALSE para ausências. Como R trata TRUE como 1 e FALSE como 0 no cálculo da média, colMeans() fornece diretamente a proporção de indivíduos com genótipo observado em cada loco.

O número de classes genotípicas é calculado, para cada coluna j, por length(unique(na.omit(ssr_raw[, j]))): na.omit() remove as ausências, unique() mantém apenas os códigos genotípicos distintos e length() conta quantas classes foram observadas. Um loco é mantido quando a taxa de chamada é igual ou superior a 0,90 — pelo menos 135 dos 150 indivíduos — e quando existem pelo menos duas classes genotípicas. Esse segundo critério remove locos sem variação observável mesmo quando a taxa de chamada é alta.

A tabela permite identificar separadamente qual critério determinou a retenção ou remoção de cada loco. A matriz ssr criada ao final contém apenas os locos que seguem para a codificação alélica do Módulo 02; ssr_raw é preservada para os diagnósticos da fonte original.

# Calcula taxa de chamada e diversidade de classes genotípicas para decidir quais locos SSR serão mantidos.
genotype_classes <- integer(ncol(ssr_raw))

for (j in seq_len(ncol(ssr_raw))) {
  # Conta quantas classes genotípicas foram observadas no loco.
  genotype_classes[j] <- length(
    unique(na.omit(ssr_raw[, j]))
  )
}

locus_audit <- data.frame(
  Locus = colnames(ssr_raw),
  N_called = colSums(!is.na(ssr_raw)),
  Call_rate = colMeans(!is.na(ssr_raw)),
  N_genotype_classes = genotype_classes
)

rownames(locus_audit) <- NULL

locus_audit$Keep_locus <-
  locus_audit$Call_rate >= CALL_RATE_MIN &
  locus_audit$N_genotype_classes >= 2

# Mantém na matriz SSR apenas os locos que passaram os critérios de qualidade.
ssr <- ssr_raw[
  ,
  locus_audit$Keep_locus,
  drop = FALSE

7. Resumo da informação genotípica

A completude genotípica também é calculada por indivíduo usando os 35 locos originais (ssr_raw). A expressão rowSums(!is.na(ssr_raw)) conta quantos locos possuem genótipo observado em cada indivíduo, enquanto rowMeans(!is.na(ssr_raw)) divide implicitamente essa contagem pelo número de locos e fornece a proporção de chamadas disponíveis. 8.1 Observações fenotípicas distantes da média

Os valores padronizados são utilizados apenas como diagnóstico descritivo. Para cada característica, calcula-se \(z=(y-\bar{y})/s\), em que \(y\) é o valor observado, \(\bar{y}\) é a média da característica e \(s\) é o desvio-padrão amostral. A chamada scale(phenotypes, center = phenotype_means, scale = phenotype_standard_deviations) aplica exatamente essa transformação a cada coluna da matriz fenotípica.

Em seguida, abs(phenotype_standardized) >= PHENOTYPE_DISTANCE_THRESHOLD compara a distância absoluta de cada valor padronizado com o limite definido, ignorando se a observação está acima ou abaixo da média. which(..., arr.ind = TRUE) retorna as posições de linha e coluna que atendem ao critério; essas posições permitem recuperar o indivíduo, a característica e o valor original. Uma observação é destacada quando \(|z|\) é de pelo menos 4, mas nenhum valor é removido ou alterado.

# Padroniza os fenótipos e identifica observações distantes da média segundo o limite definido.
phenotype_means <- colMeans(phenotypes)
phenotype_standard_deviations <- numeric(ncol(phenotypes))

for (j in seq_len(ncol(phenotypes))) {
  phenotype_standard_deviations[j] <- sd(phenotypes[, j])
}

phenotype_standardized <- scale(
  phenotypes,
  center = phenotype_means,
  scale = phenotype_standard_deviations
)

# Localiza as observações cuja distância padronizada alcança o limite definido.
extreme_positions <- which(
  abs(phenotype_standardized) >= PHENOTYPE_DISTANCE_THRESHOLD,
  arr.ind = TRUE
)

  IND = rownames(phenotypes)[extreme_positions[, "row"]],
  Trait = colnames(phenotypes)[extreme_positions[, "col"]],

  Trait_SD = phenotype_standard_deviations[extreme_positions[, "col"]],

    phenotype_standardized[extreme_positions]
