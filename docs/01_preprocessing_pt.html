1. Objetivo

A seleção genômica exige que os registros fenotípicos e os marcadores representem os mesmos indivíduos e estejam organizados na mesma ordem.

Nesta etapa, os dados fenotípicos e SSR são lidos, os identificadores dos indivíduos e dos locos são organizados, os códigos de ausência são convertidos em NA, as duas fontes são alinhadas e os locos com baixa taxa de chamada ou sem variação genotípica são removidos.

Os cinco folds da validação cruzada são criados após este pré-processamento.

4. Organização dos dados SSR

A primeira coluna da aba Genes identifica os grupos populacionais. As demais colunas contêm os 35 locos SSR.

Os identificadores dos indivíduos são obtidos da aba Genealex e mantidos como texto para preservar rótulos como 144B. As chamadas SSR ausentes, codificadas como -9, são convertidas em NA.

6. Controle de qualidade dos marcadores

Para cada loco, calculamos a taxa de chamada e o número de classes genotípicas observadas. Um loco é mantido quando apresenta taxa de chamada igual ou superior a 0,90 e pelo menos duas classes genotípicas.

genotype_classes <- integer(
  ncol(ssr_raw)
)

for (j in seq_len(ncol(ssr_raw))) {
  genotype_classes[j] <- length(
    unique(
      na.omit(
        ssr_raw[, j]
      )
    )
  )
}

locus_audit <- data.frame(
  Locus = colnames(ssr_raw),
  N_called = colSums(!is.na(ssr_raw)),
  Call_rate = colMeans(!is.na(ssr_raw)),
  N_genotype_classes = genotype_classes
)

rownames(locus_audit) <- NULL

locus_audit$Keep_locus <-
  locus_audit$Call_rate >= CALL_RATE_MIN &

ssr <- ssr_raw[
