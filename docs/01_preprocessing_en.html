Data preprocessing for genomic selection in papaya

Costa, W. G.1

2026-08-27

1. Objective

Genomic selection requires phenotypes and markers to represent the same individuals in the same order. In this module, both data sources are read, identifiers are organized, SSR missing-value codes are converted to NA, phenotypes are aligned with genotypes, and SSR loci are subjected to quality control.

The block column (BL) is removed because it is not part of the statistical model adopted in this analysis. Family (FAM) is preserved because it will be used both in the fixed-effect matrix and to stratify the cross-validation folds in Module 02. No individual is removed in this module.

Preprocessing produces three central objects for the following stages: the aligned phenotype matrix, the SSR matrix after locus quality control, and metadata containing individual and family. The diagnostics verify the consistency of these objects before genomic-matrix construction.

2. Packages, files, and parameters

The packages used in this module have distinct roles:

  • readxl: reads the Excel workbooks containing genotype and phenotype data;
  • dplyr: selects, transforms, and organizes tabular data;
  • tidyr: reshapes data between wide and long formats;
  • ggplot2: builds the quality-control and phenotype-distribution figures;
  • knitr: formats tables in R Markdown documents;
  • here: builds project-relative file paths that do not depend on the local working directory.
library(readxl)  # Read Excel workbooks.
library(dplyr)   # Manipulate and transform tables.
library(tidyr)   # Reshape data between wide and long formats.
library(ggplot2) # Build figures.
library(knitr)   # Format tables and R Markdown output.
library(here)    # Build portable project-relative paths.

Two control parameters are fixed:

  • CALL_RATE_MIN = 0.90: requires at least 90% of the calls at a locus to be available. Because the panel contains 150 individuals, this corresponds to at least 135 observed genotypes per locus. Together with the requirement of at least two genotype classes, the criterion avoids retaining loci with insufficient information to represent variation.
  • PHENOTYPE_DISTANCE_THRESHOLD = 4: flags, only for inspection, observations at least four standard deviations from the trait mean. This diagnostic rule does not remove phenotypes, cap them at a cutoff, or otherwise alter their values.
# Define the two input files and the directory where preprocessing outputs are stored.
GENOTYPE_FILE <- here("data", "papaya_ssr_genotypes.xlsx")
PHENOTYPE_FILE <- here("data", "papaya_phenotypes_2024_2025.xlsx")
OUTPUT_DIR <- here("output", "preprocessing")

# Require at least 90% available calls for an SSR locus to be retained.
CALL_RATE_MIN <- 0.90
# Use four standard deviations only as a diagnostic flagging threshold.
PHENOTYPE_DISTANCE_THRESHOLD <- 4

dir.create(OUTPUT_DIR, recursive = TRUE, showWarnings = FALSE)

3. Reading the original spreadsheets

The genotype workbook uses the Genes sheet for numerical SSR codes and the Genealex sheet for individual and locus identifiers. The Genes sheet is read without column names because its 36 columns correspond directly to the group index and the 35 SSR loci, with no column-name row. The Genealex sheet is also read without column names, but in this case because it preserves the metadata rows and original GenAlEx layout; the identifier positions are handled explicitly in the next section. Phenotypes are read from the Médias_IND_artigo sheet, which already contains column names.

The BL column is removed immediately after phenotype reading so that block is not propagated into analytical objects. The first rows make the original data organization visible, and the dimensions table checks the structure of the three sources before alignment.

4. Organizing the SSR data

The first column of Genes contains a sequential population-group index and does not represent the phenotype variable FAM; it is therefore excluded from the marker matrix. The remaining 35 columns correspond to the original SSR loci.

In Genealex, individual identifiers and locus names occupy fixed positions in the original GenAlEx layout. These positions are recovered to assign the correct row and column names to the SSR matrix.

After organization, SSR codes are stored numerically and the source missing-value code -9 is converted to NA. Thus, ssr_raw preserves the original genotypes with consistent identifiers and an explicit representation of missing calls.

# Obtain panel dimensions from `Genes`; its first column is not an SSR locus.
n_individuals <- nrow(genes)
n_loci <- ncol(genes) - 1

# Translate the `Genealex` layout: individuals start on row 4 and loci occupy alternating columns.
individual_rows <- 4:(3 + n_individuals)
locus_columns <- seq(3, 2 + 2 * n_loci, by = 2)

# Keep identifiers as text to preserve alphanumeric codes.
ids <- trimws(
  as.character(genealex[[2]][individual_rows])
)

locus_names <- trimws(
  as.character(
    unlist(genealex[3, locus_columns], use.names = FALSE)
  )
)

ssr_raw <- as.matrix(
  genes[, -1, drop = FALSE]
)

storage.mode(ssr_raw) <- "numeric"
# Convert the original missing-value code to R's standard missing value.
ssr_raw[ssr_raw == -9] <- NA_real_

rownames(ssr_raw) <- ids
colnames(ssr_raw) <- locus_names

5. Organizing and aligning phenotypes

Ten phenotype traits are used. Before alignment, the module checks that all required columns are present, that the sets of genotyped and phenotyped individuals agree, and that identifiers and locus names contain no missing or duplicated entries.

Only after these checks are phenotypes reordered to exactly match the individual sequence in the SSR matrix. Thus, corresponding rows of the genotype and phenotype objects represent the same plant. FAM is preserved as a categorical variable, whereas the ten traits are gathered into a numeric matrix for subsequent modules.

6. Marker quality control

Marker quality control considers two properties of each locus: the proportion of individuals with an observed genotype and the number of genotype classes represented. A locus is retained when its call rate is at least 0.90 — equivalent to 135 of 150 individuals — and at least two genotype classes are present.

These criteria distinguish missingness from lack of variation. A locus with high call rate can therefore still be removed if it is monomorphic in the panel. Filtering acts only on loci: ssr_raw preserves the original matrix for diagnostics, whereas ssr contains the loci passed to allele-dosage coding in Module 02.

# Compute call rate and genotype-class diversity to decide which SSR loci are retained.
genotype_classes <- integer(ncol(ssr_raw))

for (j in seq_len(ncol(ssr_raw))) {
  # Count the genotype classes observed at each locus.
  genotype_classes[j] <- length(
    unique(na.omit(ssr_raw[, j]))
  )
}

locus_audit <- data.frame(
  Locus = colnames(ssr_raw),
  N_called = colSums(!is.na(ssr_raw)),
  Call_rate = colMeans(!is.na(ssr_raw)),
  N_genotype_classes = genotype_classes
)

rownames(locus_audit) <- NULL

locus_audit$Keep_locus <-
  locus_audit$Call_rate >= CALL_RATE_MIN &
  locus_audit$N_genotype_classes >= 2

# Retain in the SSR matrix only loci that pass the quality-control criteria.
ssr <- ssr_raw[
  ,
  locus_audit$Keep_locus,
  drop = FALSE
]

8.1 Phenotype observations far from the mean

Standardized values are used only as a descriptive diagnostic. For each trait,

\[ z = \frac{y-\bar{y}}{s}, \]

where \(y\) is the observed value, \(\bar{y}\) is the trait mean, and \(s\) is the sample standard deviation. Observations whose absolute standardized distance is at least 4 standard deviations are highlighted for inspection. This procedure does not remove, cap, or transform the phenotypes used later in the models.

# Standardize phenotypes and identify observations beyond the defined distance threshold.
phenotype_means <- colMeans(phenotypes)
phenotype_standard_deviations <- numeric(ncol(phenotypes))

for (j in seq_len(ncol(phenotypes))) {
  phenotype_standard_deviations[j] <- sd(phenotypes[, j])
}

phenotype_standardized <- scale(
  phenotypes,
  center = phenotype_means,
  scale = phenotype_standard_deviations
)

# Locate observations whose standardized distance reaches the defined threshold.
extreme_positions <- which(
  abs(phenotype_standardized) >= PHENOTYPE_DISTANCE_THRESHOLD,
  arr.ind = TRUE
)

phenotype_extremes <- data.frame(
  IND = rownames(phenotypes)[extreme_positions[, "row"]],
  Trait = colnames(phenotypes)[extreme_positions[, "col"]],
  Value = phenotypes[extreme_positions],
  Trait_mean = phenotype_means[extreme_positions[, "col"]],
  Trait_SD = phenotype_standard_deviations[extreme_positions[, "col"]],
  Standardized_value = phenotype_standardized[extreme_positions],
  Absolute_standardized_distance = abs(
    phenotype_standardized[extreme_positions]
  )
)

# Sort only the diagnostic table; the `phenotypes` matrix remains unchanged.
phenotype_extremes <- phenotype_extremes[
  order(-phenotype_extremes$Absolute_standardized_distance),
]
rownames(phenotype_extremes) <- NULL
