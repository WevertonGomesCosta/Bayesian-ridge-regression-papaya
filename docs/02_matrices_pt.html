1. Objetivo

Os modelos de predição genômica utilizam matrizes numéricas que representam os efeitos fixos e a semelhança genética entre os indivíduos.

Nesta etapa, os genótipos SSR são convertidos em dosagens alélicas, os efeitos fixos de bloco e família são representados em uma matriz de delineamento, a matriz de relacionamento genômico aditivo é construída e cinco folds de validação cruzada são definidos.

As matrizes de efeitos fixos, de marcadores e de relacionamento genômico são construídas uma única vez com o conjunto pré-processado completo. Elas permanecem inalteradas entre os folds. A validação cruzada será implementada no módulo de ajuste dos modelos, substituindo por valores ausentes os fenótipos dos indivíduos de validação.

3. Codificação das dosagens alélicas

Cada código SSR contém dois rótulos alélicos. O código 12, por exemplo, representa uma cópia do alelo 1 e uma cópia do alelo 2. O código 22 representa duas cópias do alelo 2.

Uma coluna é criada para cada alelo observado em cada loco mantido. A dosagem é 0, 1 ou 2, de acordo com o número de cópias presentes em cada indivíduo.

  allele_1 <- floor(codes / 10)
  allele_2 <- codes %% 10

    unique(
      c(

      as.numeric(allele_1 == allele) +
      as.numeric(allele_2 == allele)

      colnames(ssr_full)[j],

5. Matriz completa de marcadores

As dosagens ausentes são substituídas pela média da coluna. Em seguida, cada média é subtraída de sua respectiva coluna.

A matriz \(\mathbf{M}\) resultante possui os indivíduos nas linhas e as dosagens alélicas mantidas nas colunas.

marker_means_full <- colMeans(
  dosage_full,
  na.rm = TRUE
)

dosage_full_imputed <- dosage_full

for (j in seq_len(ncol(dosage_full_imputed))) {
  missing_values <- is.na(
    dosage_full_imputed[, j]
  )

  dosage_full_imputed[
    missing_values,
    j
  ] <- marker_means_full[j]
}

M_full <- sweep(
  dosage_full_imputed,
  2,
  marker_means_full,
  FUN = "-"
)

6. Matriz completa de relacionamento genômico

Seja \(p_j\) a frequência do alelo representado pela coluna \(j\). A matriz aditiva de relacionamento genômico é calculada por

\[ \mathbf{G} = \frac{\mathbf{M}\mathbf{M}^{\mathsf{T}}} {\sum_j 2p_j(1-p_j)}. \]

allele_frequencies_full <-
  marker_means_full / 2

denominator_full <- sum(
  2 *
    allele_frequencies_full *
    (1 - allele_frequencies_full)
)

G_full <- tcrossprod(
  M_full
) / denominator_full

G_full <- (
  G_full + t(G_full)
) / 2

dimnames(G_full) <- list(
  ids,
  ids
)

eigenvalues_G_full <- eigen(
  G_full,
  symmetric = TRUE,
  only.values = TRUE
)$values

8. Cinco folds estratificados por família

Os 150 indivíduos são divididos em cinco grupos de validação. Os indivíduos de cada família são distribuídos da forma mais uniforme possível entre os folds. A semente fixa preserva a mesma alocação em todas as execuções.

set.seed(
  SEED_CV
)

family <- droplevels(
  metadata$FAM
)

folds <- integer(
  length(ids)
)

fold_load <- integer(
  N_FOLDS
)

for (family_level in levels(family)) {
  family_indices <- sample(
    which(family == family_level)
  )

  random_tie_order <- sample(
    seq_len(N_FOLDS)
  )

  ordered_folds <- order(
    fold_load,
    match(
      seq_len(N_FOLDS),
      random_tie_order
    )
  )

  family_labels <- rep(
    ordered_folds,
    length.out = length(family_indices)
  )

  folds[family_indices] <-
    family_labels

  fold_load <- fold_load + tabulate(
    family_labels,
    nbins = N_FOLDS
  )
}

9. Contrato da validação cruzada

A tabela dos folds define quais 30 indivíduos serão utilizados para validação em cada rodada. Ela não define matrizes de marcadores ou matrizes genômicas específicas por fold.

As matrizes utilizadas pelos modelos permanecem fixas:

  • X contém os efeitos de bloco e família;
  • M contém as colunas centralizadas de dosagens alélicas;
  • G contém os relacionamentos genômicos aditivos.

No próximo módulo, uma cópia do vetor fenotípico será criada para cada característica e fold. Os 30 fenótipos de validação serão substituídos por NA, enquanto X, M e G permanecerão inalteradas.
