Construção das matrizes para seleção genômica em mamoeiro

Costa, W. G.1

2026-08-27

1. Objetivo

Neste módulo, os genótipos SSR pré-processados são convertidos em dosagens alélicas. A partir dessas dosagens são construídas a matriz de marcadores centralizada M, a matriz aditiva de relacionamento genômico G e a matriz de efeitos fixos X, contendo apenas família além do intercepto. Também são definidos cinco folds de validação cruzada estratificados por família.

As matrizes são construídas uma única vez com os 150 indivíduos e permanecem inalteradas entre os folds. No Módulo 03, somente o vetor fenotípico será mascarado para formar os conjuntos de treinamento e validação.

Como os candidatos de todos os folds já estão genotipados, a filtragem dos marcadores, as frequências alélicas, a imputação pela média, M e G são definidas a partir do painel genotípico completo e depois mantidas fixas. Nenhum fenótipo de validação participa dessas etapas. Esse desenho corresponde a um cenário transdutivo de candidatos genotipados e não deve ser interpretado como validação externa em uma nova população genotípica.

O módulo produz quatro componentes reutilizados diretamente no Módulo 03: a matriz de efeitos fixos X, a matriz centralizada de marcadores M, a matriz de relacionamento genômico G e a tabela cv_folds, que identifica o fold de validação de cada indivíduo. Os diagnósticos verificam a codificação alélica, a centralização, o relacionamento genômico e a estratificação por família.

O objeto preprocessing_object.rds, produzido no Módulo 01, fornece os indivíduos, fenótipos, famílias e locos SSR que entram na construção das matrizes.

Três parâmetros são definidos neste módulo:

  • N_FOLDS = 5: divide os 150 indivíduos em cinco grupos de validação com 30 indivíduos cada e 120 indivíduos de treinamento. Cada indivíduo participa uma única vez da validação; não se trata de validação cruzada repetida.

3. Codificação das dosagens alélicas

Cada código SSR contém dois rótulos alélicos. O código 12, por exemplo, representa uma cópia do alelo 1 e uma cópia do alelo 2, enquanto 22 representa duas cópias do alelo 2. Para cada alelo observado em cada loco mantido, a dosagem de um indivíduo é calculada como a soma de duas funções indicadoras: uma para cada posição alélica do genótipo. Assim, a coluna assume 0, 1 ou 2 conforme o indivíduo carregue zero, uma ou duas cópias daquele alelo.

Uma coluna é criada para cada combinação loco–alelo, e chamadas SSR ausentes permanecem como NA até a etapa de imputação. Antes de qualquer filtragem de colunas alélicas, as dosagens de todos os alelos de um loco diploide somam 2 para cada genótipo observado. Essa propriedade será usada posteriormente como diagnóstico da codificação.

A codificação é construída em etapas que correspondem diretamente às operações do código:

  1. Seleção dos locos mantidos. locus_audit_full$Locus[locus_audit_full$Keep_locus] usa o vetor lógico Keep_locus para recuperar somente os nomes aprovados no controle de qualidade. Em seguida, ssr_raw[, retained_loci_full, drop = FALSE] mantém todas as linhas e apenas essas colunas; drop = FALSE preserva a estrutura matricial mesmo quando a seleção contém poucas colunas.
  2. Separação dos dois alelos do código SSR. Para um código como 12, floor(codes / 10) retorna o algarismo das dezenas, isto é, o primeiro alelo (1). O operador %% devolve o resto da divisão inteira; assim, codes %% 10 retorna o algarismo das unidades, correspondente ao segundo alelo (2).
  3. Contagem das cópias de cada alelo. As comparações allele_1 == allele e allele_2 == allele indicam se o alelo está presente em cada posição. as.numeric() converte TRUE em 1 e FALSE em 0; a soma das duas posições produz a dosagem 0, 1 ou 2. Quando o código SSR é ausente, a dosagem é mantida como NA.
  4. Montagem da matriz. Cada vetor de dosagem é armazenado em uma lista. Ao final, do.call(cbind, dosage_parts_full) combina esses vetores como colunas de uma única matriz, enquanto bind_rows(allele_map_parts_full) reúne os metadados que ligam cada coluna ao loco e ao alelo de origem.
# Expande cada loco multialélico em colunas de dosagem por alelo e registra a origem de cada coluna.
retained_loci_full <- locus_audit_full$Locus[
  locus_audit_full$Keep_locus
]

ssr_full <- ssr_raw[
  ,
  retained_loci_full,
  drop = FALSE
]

dosage_parts_full <- list()
allele_map_parts_full <- list()
marker_counter_full <- 0L

  # Separa os dois alelos codificados em cada genótipo SSR.
  codes <- ssr_full[, j]
  allele_1 <- floor(codes / 10)
  allele_2 <- codes %% 10

  # Lista os alelos observados no loco atual.
  observed_alleles <- sort(
    unique(
      c(
        allele_1[!is.na(codes)],
        allele_2[!is.na(codes)]
      )
    )
  )

  for (allele in observed_alleles) {
    marker_counter_full <- marker_counter_full + 1L

    # Conta 0, 1 ou 2 cópias do alelo em cada indivíduo.
    dosage <-
      as.numeric(allele_1 == allele) +
      as.numeric(allele_2 == allele)
    dosage[is.na(codes)] <- NA_real_

    # Cria um identificador único para a combinação entre loco e alelo.
    marker_name <- paste0(
      colnames(ssr_full)[j],
      "__A",
      allele
    )

    allele_map_parts_full[[marker_counter_full]] <- data.frame(
      Locus = colnames(ssr_full)[j],
      Allele = allele,
      Marker = marker_name
    )
  }
}

4. Frequências alélicas e retenção das colunas de dosagem

A frequência de uma coluna alélica é calculada como a média das dosagens observadas dividida por 2, pois cada indivíduo diploide pode contribuir com duas cópias do alelo. O cálculo ignora NA nesta etapa, de modo que a frequência usa apenas chamadas disponíveis.

São mantidas colunas com frequência entre 0,05 e 0,95 e desvio-padrão de dosagem positivo. Os limites inferior e superior são simétricos: removem alelos muito raros e colunas praticamente fixadas, enquanto Dosage_sd > 0 garante variação observável. O filtro atua sobre colunas de dosagem alélica; ele não remove indivíduos.

No código, colMeans(dosage_full_raw, na.rm = TRUE) / 2 calcula simultaneamente a frequência de todas as colunas: na.rm = TRUE exclui chamadas ausentes do cálculo da média e a divisão por 2 converte a dosagem média, que varia de 0 a 2, em frequência alélica entre 0 e 1. O laço com sd(..., na.rm = TRUE) calcula o desvio-padrão de cada coluna. Por fim, is.finite() impede que resultados não finitos sejam aceitos antes de aplicar os limites de frequência e a condição Dosage_sd > 0.

# Calcula frequência e variabilidade das dosagens para filtrar colunas alélicas informativas.
allele_audit_full$Allele_frequency <-
  colMeans(dosage_full_raw, na.rm = TRUE) / 2

dosage_sd_full <- numeric(ncol(dosage_full_raw))

for (j in seq_len(ncol(dosage_full_raw))) {
  dosage_sd_full[j] <- sd(
    dosage_full_raw[, j],
    na.rm = TRUE
  )
}

allele_audit_full$Dosage_sd <- dosage_sd_full

5. Matriz de marcadores

As dosagens ausentes são substituídas pela média da respectiva coluna calculada no painel genotípico completo. marker_means_full <- colMeans(dosage_full, na.rm = TRUE) calcula uma média para cada coluna. Dentro do laço, is.na(dosage_full_imputed[, j]) identifica as posições ausentes da coluna j, que recebem marker_means_full[j].

Depois da imputação, sweep(dosage_full_imputed, 2, marker_means_full, FUN = "-") centraliza as dosagens. O argumento 2 indica que a operação é feita por colunas, e FUN = "-" subtrai de cada valor a média correspondente. Como a mesma média foi usada na imputação, uma dosagem imputada passa a valer exatamente zero em M: ela representa ausência de desvio em relação à frequência média da coluna, e não uma nova classe genotípica.

A matriz resultante é denotada por \(\mathbf M\). Suas colunas são centralizadas, mas não padronizadas para variância unitária. A imputação utiliza somente informação genotípica dos 150 candidatos; nenhum fenótipo de validação entra no cálculo.

# Imputa dosagens ausentes pelas médias, centraliza as colunas e constrói a matriz de marcadores M.
marker_means_full <- colMeans(
  dosage_full,
  na.rm = TRUE
)

dosage_full_imputed <- dosage_full

for (j in seq_len(ncol(dosage_full_imputed))) {
  # Localiza as dosagens ausentes na coluna atual.
  missing_values <- is.na(dosage_full_imputed[, j])

  # Imputa a média da coluna.
  dosage_full_imputed[
    missing_values,
    j
  ] <- marker_means_full[j]
}

# Centraliza cada coluna da matriz de dosagens.
M_full <- sweep(
  dosage_full_imputed,
  2,
  marker_means_full,
  FUN = "-"
)

6. Matriz de relacionamento genômico

Seja \(p_j\) a frequência do alelo representado pela coluna \(j\). Utilizando uma escala do tipo VanRaden baseada em frequências alélicas (VanRaden 2008), a matriz aditiva de relacionamento genômico é calculada por

\[ \mathbf G = \frac{\mathbf M\mathbf M^{\mathsf T}} {\sum_j 2p_j(1-p_j)}. \]

No código, allele_frequencies_full <- marker_means_full / 2 recupera \(p_j\) porque a média da dosagem corresponde a \(2p_j\). tcrossprod(M_full) calcula diretamente \(\mathbf M\mathbf M^{\mathsf T}\), isto é, um produto entre indivíduos a partir das colunas centralizadas. A divisão por denominator_full aplica a escala definida na fórmula. Depois, (G_full + t(G_full)) / 2 remove apenas pequenas diferenças numéricas entre elementos simétricos, e eigen(..., symmetric = TRUE, only.values = TRUE) obtém os autovalores usados no diagnóstico de semidefinição positiva.

# Recupera p_j a partir da média da dosagem, que corresponde a 2p_j.
allele_frequencies_full <- marker_means_full / 2

# Calcula a escala de VanRaden a partir das frequências das colunas alélicas.
denominator_full <- sum(
  2 *
    allele_frequencies_full *
    (1 - allele_frequencies_full)
)

# Converte produtos de dosagens centralizadas em relacionamento genômico escalonado.
G_full <- tcrossprod(M_full) / denominator_full

# Remove apenas diferenças numéricas de simetria.
G_full <- (G_full + t(G_full)) / 2

dimnames(G_full) <- list(ids, ids)

eigenvalues_G_full <- eigen(
  G_full,
  symmetric = TRUE,
  only.values = TRUE
)$values

O denominador informa a escala usada na construção de G. A média da diagonal resume o relacionamento de cada indivíduo consigo mesmo nessa escala e não é forçada a ser exatamente 1. A diferença de simetria deve ser próxima de zero. Como G é construída por produto cruzado, ela é semidefinida positiva em teoria; por isso, um menor autovalor ligeiramente negativo, quando restrito à precisão numérica, deve ser interpretado como arredondamento e não como evidência de relacionamento negativo.

7. Matriz de efeitos fixos

Família é o único efeito fixo categórico. Com ~ FAM, model.matrix() usa a codificação de contrastes padrão do R: cria uma coluna de intercepto e colunas indicadoras suficientes para representar as diferenças entre os níveis de família em relação a uma categoria de referência. Assim, X incorpora a estrutura familiar sem tratar FAM como variável numérica.

No Módulo 03, a coluna de intercepto será removida de X porque o BGLR já ajusta intercepto automaticamente; manter ambos duplicaria o mesmo efeito constante.

8. Cinco folds estratificados por família

A estratificação por família direciona a avaliação para a predição entre indivíduos da população de melhoramento representada. Não se trata de um desenho leave-family-out e, portanto, o desempenho não representa famílias inteiramente novas.

Os 150 indivíduos são divididos em cinco grupos de validação de 30 indivíduos. A construção é feita família por família e pode ser acompanhada diretamente pelas funções usadas no código:

  1. which(family == family_level) localiza os indivíduos da família atual e sample() embaralha suas posições.
  2. seq_len(N_FOLDS) gera os números dos cinco folds. Uma segunda chamada a sample() cria uma ordem aleatória usada somente para desempatar folds com a mesma carga acumulada.
  3. order(fold_load, match(seq_len(N_FOLDS), random_tie_order)) prioriza primeiro os folds menos preenchidos e usa a ordem aleatória apenas quando duas cargas são iguais.
  4. rep(ordered_folds, length.out = length(family_indices)) repete ciclicamente essa ordem até produzir um rótulo de fold para cada membro da família.
  5. tabulate(family_labels, nbins = N_FOLDS) conta quantos indivíduos acabaram de ser enviados a cada fold e atualiza fold_load.

Esse procedimento espalha os membros de cada família entre os folds ao mesmo tempo que mantém os tamanhos totais equilibrados. Depois da alocação, apply(family_fold_table, 1, max) e apply(family_fold_table, 1, min) calculam, para cada linha da tabela — isto é, para cada família — as maiores e menores contagens entre folds. O argumento 1 indica operação por linhas; a diferença entre máximo e mínimo forma family_balance.

A semente fixa preserva exatamente a mesma partição entre execuções. A mesma tabela de folds será usada para todas as dez características e todos os métodos; portanto, diferenças entre modelos não decorrem de partições de validação diferentes.

# Inicializa a partição estratificada e controla a carga total acumulada de cada fold.
set.seed(SEED_CV)

family <- droplevels(metadata$FAM)
folds <- integer(length(ids))
fold_load <- integer(N_FOLDS)

for (family_level in levels(family)) {
  # Embaralha os indivíduos da família atual.
  family_indices <- sample(
    which(family == family_level)
  )

  # Define uma ordem aleatória para desempatar folds com a mesma carga.
  random_tie_order <- sample(seq_len(N_FOLDS))

  ordered_folds <- order(
    fold_load,
    match(seq_len(N_FOLDS), random_tie_order)
  )

  # Distribui os indivíduos da família entre os cinco folds.
  family_labels <- rep(
    ordered_folds,
    length.out = length(family_indices)
  )

  folds[family_indices] <- family_labels

  fold_load <- fold_load + tabulate(
    family_labels,
    nbins = N_FOLDS
  )
}

11. Diagnósticos das matrizes construídas

Todas as colunas alélicas que atendem aos filtros declarados são mantidas; nenhuma categoria é descartada artificialmente apenas para impor posto completo. Quando todos os alelos de um loco permanecem representados, suas dosagens somam 2 em cada indivíduo diploide e existe uma dependência linear exata entre essas colunas. Por isso, coeficientes de alelos individuais não são interpretados isoladamente; os módulos seguintes se concentram nas predições e nos valores genômicos.

No conjunto de dados analisado, as 72 colunas de dosagem não representam 72 dimensões independentes. O limite estrutural de posto imposto pelas dependências intra-loco é calculado por sum(table(...)- 1L): table() conta quantas colunas alélicas foram mantidas em cada loco, subtrair 1 fornece \(k_l-1\) para cada loco e sum() reúne essas contribuições. Esse valor representa o máximo permitido pelas dependências intra-loco quando não existem dependências lineares adicionais entre locos; o posto observado de M é então comparado a esse limite.

A propriedade diploide é verificada loco a loco com rowSums(...) - 2: rowSums() soma as dosagens alélicas mantidas de cada indivíduo e a diferença em relação a 2 deve ser numericamente nula. A centralização é verificada pelas médias das colunas de M, e tcrossprod(M_full) / denominator_full reconstrói G para comparação com a matriz armazenada. Simetria, posto, diagonal e menor autovalor completam a checagem numérica de G.
