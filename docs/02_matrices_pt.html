Construção das matrizes para seleção genômica em mamoeiro

Costa, W. G.1

2026-08-31

1. Objetivo

Neste módulo, os genótipos SSR pré-processados são convertidos em dosagens alélicas. A partir dessas dosagens são construídas a matriz de marcadores centralizada M, a matriz aditiva de relacionamento genômico G e a matriz de efeitos fixos X, contendo apenas família além do intercepto. Também são definidos cinco folds de validação cruzada estratificados por família.

As matrizes são construídas uma única vez com os 150 indivíduos e permanecem inalteradas entre os folds. No Módulo 03, somente o vetor fenotípico será mascarado para formar os conjuntos de treinamento e validação.

Como os candidatos de todos os folds já estão genotipados, a filtragem dos marcadores, as frequências alélicas, a imputação pela média, M e G são definidas a partir do painel genotípico completo e depois mantidas fixas. Nenhum fenótipo de validação participa dessas etapas. Esse desenho corresponde a um cenário transdutivo de candidatos genotipados e não deve ser interpretado como validação externa em uma nova população genotípica.

O módulo produz quatro componentes reutilizados diretamente no Módulo 03: a matriz de efeitos fixos X, a matriz centralizada de marcadores M, a matriz de relacionamento genômico G e a tabela cv_folds, que identifica o fold de validação de cada indivíduo. Os diagnósticos verificam a codificação alélica, a centralização, o relacionamento genômico e a estratificação por família.

2.1 Objeto de entrada e parâmetros

O objeto preprocessing_object.rds, produzido no Módulo 01, fornece os indivíduos, fenótipos, famílias e locos SSR que entram na construção das matrizes.

Três parâmetros são definidos neste módulo:

  • N_FOLDS = 5: divide os 150 indivíduos em cinco grupos de validação com 30 indivíduos cada e 120 indivíduos de treinamento. Cada indivíduo participa uma única vez da validação; não se trata de validação cruzada repetida.
  • SEED_CV = 20260723: reproduz exatamente a mesma alocação estratificada dos indivíduos entre os folds. A semente controla apenas a reprodutibilidade da partição e não possui interpretação inferencial.

3. Codificação das dosagens alélicas

3.1 Do código SSR à dosagem por alelo

Cada código SSR contém dois rótulos alélicos. O código 12, por exemplo, representa uma cópia do alelo 1 e uma cópia do alelo 2, enquanto 22 representa duas cópias do alelo 2. Para cada alelo observado em cada loco mantido, a dosagem de um indivíduo é calculada como a soma de duas funções indicadoras: uma para cada posição alélica do genótipo. Assim, a coluna assume 0, 1 ou 2 conforme o indivíduo carregue zero, uma ou duas cópias daquele alelo.

Uma coluna é criada para cada combinação loco–alelo, e chamadas SSR ausentes permanecem como NA até a etapa de imputação. Antes de qualquer filtragem de colunas alélicas, as dosagens de todos os alelos de um loco diploide somam 2 para cada genótipo observado. Essa propriedade será usada posteriormente como diagnóstico da codificação.

3.2 Expansão dos locos em colunas alélicas

A codificação percorre os locos mantidos, identifica os alelos observados em cada um e cria uma coluna de dosagem para cada combinação loco–alelo. Os metadados preservam a correspondência entre cada coluna, seu loco e o alelo representado. O código abaixo implementa essa expansão sem remover indivíduos.

# Expande cada loco multialélico em colunas de dosagem por alelo e registra a origem de cada coluna.

4. Frequências alélicas e retenção das colunas de dosagem

4.1 Cálculo das frequências alélicas

A frequência de uma coluna alélica é calculada como a média das dosagens observadas dividida por 2, pois cada indivíduo diploide pode contribuir com duas cópias do alelo. O cálculo ignora NA nesta etapa, de modo que a frequência usa apenas chamadas disponíveis.

4.2 Critérios de retenção das colunas alélicas

São mantidas colunas com frequência entre 0,05 e 0,95 e desvio-padrão de dosagem positivo. Os limites inferior e superior são simétricos: removem alelos muito raros e colunas praticamente fixadas, enquanto Dosage_sd > 0 garante variação observável. O filtro atua sobre colunas de dosagem alélica; ele não remove indivíduos.

5. Matriz de marcadores

5.1 Imputação das dosagens ausentes

As dosagens ausentes são imputadas pela média da respectiva coluna, calculada no painel genotípico completo. Essa etapa completa a matriz de dosagens sem criar uma nova categoria genotípica e sem utilizar informação fenotípica.

# Calcula as médias das colunas e imputa as dosagens ausentes.
marker_means_full <- colMeans(
  dosage_full,
  na.rm = TRUE
)

dosage_full_imputed <- dosage_full

for (j in seq_len(ncol(dosage_full_imputed))) {
  missing_values <- is.na(dosage_full_imputed[, j])

  dosage_full_imputed[
    missing_values,
    j
  ] <- marker_means_full[j]
}

5.2 Centralização e construção de M

Depois da imputação, cada coluna é centralizada subtraindo a mesma média usada na imputação. A matriz resultante é denotada por \(\mathbf M\). Suas colunas são centralizadas, mas não padronizadas para variância unitária.

Como consequência, uma dosagem imputada assume valor zero em M, indicando ausência de desvio em relação à média da coluna, e não uma nova classe genotípica. A imputação e a centralização utilizam somente informação genotípica dos 150 candidatos; nenhum fenótipo de validação participa dessas operações.

M_full <- sweep(
  dosage_full_imputed,
  2,
  marker_means_full,
  FUN = "-"
)

6. Matriz de relacionamento genômico

6.1 Definição e escala de G

Seja \(p_j\) a frequência do alelo representado pela coluna \(j\). Utilizando uma escala do tipo VanRaden baseada em frequências alélicas (VanRaden 2008), a matriz aditiva de relacionamento genômico é calculada por

\[ \mathbf G = \frac{\mathbf M\mathbf M^{\mathsf T}} {\sum_j 2p_j(1-p_j)}. \]

Como um loco SSR pode originar várias colunas alélicas, essas colunas não devem ser interpretadas como marcadores independentes. Quando todos os alelos de um mesmo loco diploide permanecem representados, suas dosagens somam 2 em cada indivíduo. Depois da centralização, os desvios dessas colunas somam zero, produzindo uma dependência linear estrutural entre elas.

Essa dependência não impede a construção de G. A matriz G não exige a inversão de M nem a estimação separada de um coeficiente identificável para cada coluna alélica. Em vez disso, o produto cruzado M M^T agrega, para cada par de indivíduos, a concordância entre seus perfis de desvios de dosagem. Assim, um loco multialélico contribui para o relacionamento por meio do conjunto de seus alelos, enquanto a dependência interna entre as colunas permanece uma propriedade esperada da codificação.

6.2 Construção da matriz G

As frequências alélicas usadas na escala são obtidas das médias das dosagens, pois a dosagem média corresponde a \(2p_j\). Para cada coluna alélica, o termo \(2p_j(1-p_j)\) fornece uma escala de variabilidade baseada em sua frequência; a soma desses termos forma um denominador global para todas as colunas. Como M é centralizada, mas não padronizada coluna a coluna, esse denominador transforma o produto cruzado bruto em uma escala comum de relacionamento genômico.

Para dois indivíduos, uma célula fora da diagonal de \(\mathbf M\mathbf M^{\mathsf T}\) é o produto interno de seus perfis de dosagem centralizada. Desvios na mesma direção contribuem positivamente, enquanto desvios em direções opostas contribuem negativamente. Após a divisão pelo denominador, as células fora da diagonal de G descrevem o relacionamento genômico relativo entre pares de indivíduos, tomando as frequências alélicas deste painel como referência. Um valor negativo indica menor similaridade genômica relativa a essa referência, e não uma relação biologicamente antagônica.

Na diagonal, cada indivíduo é comparado consigo mesmo; por isso, os elementos diagonais resumem sua similaridade genômica consigo próprio na escala adotada. Como a normalização é global e não força individualmente cada diagonal, esses valores não precisam ser exatamente iguais a 1. A matriz resultante é simetrizada numericamente antes da avaliação de seus autovalores.

# Recupera p_j a partir da média da dosagem, que corresponde a 2p_j.
allele_frequencies_full <- marker_means_full / 2

# Calcula a escala de VanRaden a partir das frequências das colunas alélicas.
denominator_full <- sum(
  2 *
    allele_frequencies_full *
    (1 - allele_frequencies_full)
)


# Converte produtos de dosagens centralizadas em relacionamento genômico escalonado.
G_full <- tcrossprod(M_full) / denominator_full

# Remove apenas diferenças numéricas de simetria.
G_full <- (G_full + t(G_full)) / 2

dimnames(G_full) <- list(ids, ids)

eigenvalues_G_full <- eigen(

  symmetric = TRUE,

O denominador informa a escala usada na construção de G. A média da diagonal resume o relacionamento de cada indivíduo consigo mesmo nessa escala e não é forçada a ser exatamente 1. A diferença de simetria deve ser próxima de zero. Como G é construída por produto cruzado, ela é semidefinida positiva em teoria; por isso, um menor autovalor ligeiramente negativo, quando restrito à precisão numérica, deve ser interpretado como arredondamento e não como evidência de relacionamento negativo.

7. Matriz de efeitos fixos

Família é o único efeito fixo categórico. Com ~ FAM, model.matrix() usa a codificação de contrastes padrão do R: cria uma coluna de intercepto e colunas indicadoras suficientes para representar as diferenças entre os níveis de família em relação a uma categoria de referência. Assim, X incorpora a estrutura familiar sem tratar FAM como variável numérica.

No Módulo 03, a coluna de intercepto será removida de X porque o BGLR já ajusta intercepto automaticamente; manter ambos duplicaria o mesmo efeito constante.

# Constrói a matriz de desenho do único efeito fixo categórico da análise.

8. Desenho da validação cruzada

8.1 Cenário de avaliação

A estratificação por família direciona a avaliação para a predição entre indivíduos da população de melhoramento representada. Não se trata de um desenho leave-family-out e, portanto, o desempenho não representa famílias inteiramente novas.

8.2 Construção dos folds estratificados

Os 150 indivíduos são distribuídos em cinco grupos de validação de 30 indivíduos. A alocação é realizada família por família: os indivíduos de cada família são embaralhados e distribuídos entre os folds, com prioridade para aqueles que possuem menor número acumulado de indivíduos. Esse procedimento mantém simultaneamente a representação das famílias e o equilíbrio dos tamanhos totais.

Depois da alocação, o equilíbrio dentro de cada família é resumido pela diferença entre sua maior e sua menor contagem nos cinco folds. Esse diagnóstico é armazenado em family_balance e permite verificar diretamente a qualidade da estratificação.

A semente fixa preserva exatamente a mesma partição entre execuções. A mesma tabela de folds será usada para todas as dez características e todos os métodos; portanto, diferenças entre modelos não decorrem de partições de validação diferentes.

    which(family == family_level)
  )

  # Define uma ordem aleatória para desempatar folds com a mesma carga.
  random_tie_order <- sample(seq_len(N_FOLDS))

    fold_load,
    match(seq_len(N_FOLDS), random_tie_order)

    ordered_folds,

10. Diagnósticos das matrizes construídas

10.1 Dependência estrutural e posto de M

Todas as colunas alélicas que atendem aos filtros declarados são mantidas; nenhuma categoria é descartada artificialmente apenas para impor posto completo. Quando todos os alelos de um loco permanecem representados, suas dosagens somam 2 em cada indivíduo diploide e existe uma dependência linear exata entre essas colunas. Por isso, coeficientes de alelos individuais não são interpretados isoladamente; os módulos seguintes se concentram nas predições e nos valores genômicos.

No conjunto de dados analisado, as 72 colunas de dosagem não representam 72 dimensões independentes. Quando todos os alelos de um mesmo loco são mantidos, suas dosagens apresentam uma dependência linear decorrente da condição diploide. O limite estrutural de posto de M soma, para cada loco com \(k_l\) colunas alélicas mantidas, a contribuição \(k_l-1\). O posto observado é comparado a esse limite para verificar se existem dependências lineares adicionais entre locos.

10.2 Verificações numéricas consolidadas

A propriedade diploide da codificação é verificada antes do filtro das colunas alélicas: para cada loco SSR mantido no Módulo 01, as dosagens de todos os alelos originalmente codificados para um genótipo observado devem somar 2. Chamadas SSR ausentes são excluídas dessa verificação da codificação, em vez de serem imputadas para esse fim. A centralização de M é avaliada pelas médias de suas colunas, e G é reconstruída a partir de M para confirmar consistência numérica. Simetria, posto, diagonal e menor autovalor completam os diagnósticos da matriz de relacionamento genômico.
