Presentation of results

1. Objective

This module turns the results derived in Module 04 into a visual and tabular synthesis for scientific reading. If Module 04 answered how the evidence is combined to reach the decisions, Module 05 answers how those decisions and their limitations should be read.

The sequence follows the analytical reasoning: first compare the seven methods, then present the trait-specific decisions, illustrate MCMC diagnostics and across-fold stability, and finally show exploratory genomic rankings and recurrence across traits. No table or figure on this page constitutes a new selection or inferential step; they present results already defined upstream.

2. Packages, results, and graphical style

2.1 Packages used

The packages used here have distinct roles:

  • dplyr: organizing, joining, and transforming result tables;
  • ggplot2: building comparison and diagnostic figures;
  • ggthemes: applying the GDocs theme and scales to categorical figures;
  • knitr: formatting the tables presented on the page;
  • here: building project-relative paths.

2.4 Figure hierarchy

The figures in this module do not have the same interpretive role. The OOF-correlation comparison in Section 3.1 is the primary predictive-performance figure. The mu traces and across-fold stability are descriptive diagnostics that contextualize the selected methods without redefining the choice. Computational time provides operational context. The heatmap of OOF genomic values is an exploratory summary of associations among cross-fitted scores, not a genetic-correlation matrix from a multivariate model.

The visual reading should therefore follow this priority: predictive performance → diagnostics → operational context and exploratory associations. None of the complementary figures creates an additional selection criterion.

4. Selected methods by trait

4.1 Consolidated decision tables

The following two tables do not rerun method selection. They reorganize the decision already consolidated in Module 04 into a main table of decision and predictive evidence and a complementary table of fit evidence and diagnostics. A provisional status still requires review even though a method appears as selected.

In the first table, Predictive_loss is the difference between the pooled OOF correlation of the predictive winner and that of the selected method. A value of zero means that they coincide; a positive value shows how much pooled OOF correlation was given up by the selection rule. This column is descriptive and is neither a training loss function nor an additional selection criterion.

To reduce presentation width without losing information, the results are organized into two complementary tables. The first concentrates the decision and primary predictive evidence: selected method, reason for the choice, status, predictive and DIC winners, Predictive_loss, OOF correlation, RMSE, and predictive direction. The second collects the complementary fit and diagnostic evidence: explicit RR-BLUP preference, nominal p-value, DIC, Delta_DIC, Wprob, ER, and the MCMC indicators.

The objects created in the block below are presentation-only. Both are derived directly from model_selection and only translate labels, select columns, and format numbers; they do not recompute metrics, reapply the selection rule, filter traits, or change the selected method.

5. Illustrative MCMC trace of mu (fold 1) for selected methods

5.1 Illustrative scope and chain preparation

For each trait, this section shows the posterior chain of \(\mu\) from fold 1 of the selected method and its running mean. Fold 1 is only a consistent visual illustration across traits; convergence assessment remains based on ESS and Geweke diagnostics over all five folds.

Module 05 reads only the previously saved mu chains for the selected methods. Burn-in and thinning inherited from Module 03 are respected; the running mean uses the full available posterior chain, while point reduction affects only trace readability.

# Convert burn-in to the saved-sample scale and prepare the posterior mu trace.
burn_in_saved <-
  models_object$settings$burn_in /
  models_object$settings$thin

selected_method_lookup <- setNames(
  model_selection$Selected_method,
  model_selection$Trait
)

trace_parts <- vector("list", length(traits))

for (trait_index in seq_along(traits)) {
  # Identify the trait and selected method.
  trait_name <- traits[trait_index]
  method_name <- selected_method_lookup[trait_name]

  # Locate the mu chain from the first fold.
  mu_file <- file.path(
    here("output", "models", "bglr"),
    trait_name,
    "F1",
    method_name,
    "bglr_mu.dat"
  )

  mu_full <- scan(mu_file, quiet = TRUE)

  # Remove samples corresponding to burn-in.
  posterior_mu <- mu_full[
    seq.int(burn_in_saved + 1L, length(mu_full))
  ]

  iteration <- seq.int(
    from = models_object$settings$burn_in + models_object$settings$thin,
    by = models_object$settings$thin,
    length.out = length(posterior_mu)
  )

  # Compute the running mean and reduce point density for plotting.
  running_mean <- cumsum(posterior_mu) / seq_along(posterior_mu)
  keep_index <- seq.int(1L, length(posterior_mu), by = 100L)

  trace_parts[[trait_index]] <- data.frame(
    Trait = trait_name,
    Method = method_name,
    Facet = paste0(trait_name, " — ", method_labels[method_name]),
    Iteration = iteration[keep_index],
    Posterior_mu = posterior_mu[keep_index],
    Running_mean = running_mean[keep_index]
  )
}

selected_mu_trace <- bind_rows(trace_parts)

Selection_frequency uses the number of positive-OOF traits as its denominator, not necessarily all 10 original traits. Recurrence supported by weak positive OOF signals remains exploratory. N_traits, frequency, and ranks are not combined into a multi-trait index; therefore, greater recurrence does not demonstrate joint superiority across multiple traits.

12. Summary

The final reading should preserve the hierarchy established throughout the analysis: OOF performance drives predictive comparison; DIC, across-fold stability, and MCMC diagnostics provide complementary context; rankings are produced only when OOF direction is positive; and recurrence summarizes overlap among rankings without constructing a multi-trait index. All conclusions remain conditional on the represented breeding population, the available SSR panel, and the transductive validation design. For operational selection, OOF rankings should be treated as exploratory evidence rather than substitutes for final breeding values from a prediction stage designed for decision making.
