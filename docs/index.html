English

Project overview

This project is a reproducible tutorial for genomic prediction and selection in papaya using multi-allelic SSR markers.

The analytical dataset contains 150 individuals, 34 retained SSR loci expanded into 72 allele-dosage columns, and 10 phenotypic traits. Family is the only categorical fixed effect used in the prediction models; the block column is removed during phenotype preprocessing.

Seven methods are compared: RR-BLUP/BRR, BayesA, BayesB, BayesB2, BayesC, Bayesian Lasso, and GBLUP.

Analysis sequence

The tutorial is organized into five modules with non-overlapping responsibilities:

  1. Data preprocessing and diagnostics
  2. Matrix construction and diagnostics
  3. Model fitting and MCMC diagnostics
  4. Derivation and model selection
  5. Results presentation

Module 03 fits the models, Module 04 derives and stores the canonical analytical results, and Module 05 only presents those results in final tables and figures.

The analytical matrices X, M, and G are constructed once using all 150 aligned individuals. X contains the intercept and family indicators; BGLR handles the intercept internally, so only family is passed through the FIXED component. The same matrices are used in the five deterministic family-stratified folds. For validation, only the phenotype vector is masked; the original validation observations are retained separately for OOF assessment.

Português

Visão geral do projeto

Este projeto é um tutorial reprodutível de predição e seleção genômica em mamoeiro utilizando marcadores SSR multialélicos.

O conjunto analítico contém 150 indivíduos, 34 locos SSR mantidos e expandidos em 72 colunas de dosagem alélica e 10 características fenotípicas. Família é o único efeito fixo categórico utilizado nos modelos de predição; a coluna de bloco é removida durante o pré-processamento dos fenótipos.

Sete métodos são comparados: RR-BLUP/BRR, BayesA, BayesB, BayesB2, BayesC, Lasso Bayesiano e GBLUP.

Sequência das análises

O tutorial está organizado em cinco módulos com responsabilidades não sobrepostas:

  1. Pré-processamento e diagnóstico dos dados
  2. Construção e diagnóstico das matrizes
  3. Ajuste dos modelos e diagnósticos MCMC
  4. Derivação e seleção dos modelos
  5. Apresentação dos resultados

O Módulo 03 ajusta os modelos, o Módulo 04 deriva e armazena os resultados analíticos canônicos e o Módulo 05 apenas apresenta esses resultados em tabelas e figuras finais.

As matrizes analíticas X, M e G são construídas uma única vez com os 150 indivíduos alinhados. X contém o intercepto e os indicadores de família; como o BGLR já ajusta o intercepto internamente, somente família é fornecida pelo componente FIXED. As mesmas matrizes são utilizadas nos cinco folds determinísticos e estratificados por família. Na validação, apenas o vetor fenotípico é mascarado; as observações originais de validação são mantidas separadamente para avaliação OOF.
