English

Project overview

This project compares genomic prediction methods for production and fruit-quality traits in papaya using multi-allelic SSR markers.

The validated analytical dataset contains:

  • 150 individuals;
  • 35 original SSR loci;
  • 34 retained SSR loci;
  • 72 retained allele-dosage columns;
  • 10 phenotypic traits;
  • block and family as categorical fixed effects.

The alphanumeric identifier 144B is preserved throughout data alignment.

Prediction methods

The eight methods are:

  1. Bayesian ridge regression (BRR);
  2. BayesA;
  3. BayesB;
  4. BayesB with pi = 1e-5 as the reference article’s zero-effect probability;
  5. BayesC;
  6. Bayesian Lasso (BL);
  7. RR-BLUP;
  8. GBLUP.

Because BGLR defines probIn as the probability of a non-zero marker effect, the special BayesB configuration uses probIn = 1 - 1e-5.

Matrix and validation contract

The fixed-effect matrix X, the centered allele-dosage matrix M, and the additive genomic relationship matrix G are constructed once with all 150 aligned individuals.

Their validated dimensions are:

Matrix Dimensions Rank
X 150 × 19 19
M 150 × 72 38
G 150 × 150 38

The same matrices are used in all five family-stratified folds. Each fold has 30 validation individuals, 120 training individuals, and 3 validation individuals from each family.

For each trait and fold, cross-validation changes only the phenotype vector: the 30 validation phenotypes are replaced by NA. The original observed values are retained separately for calculating predictive metrics.

Phenotypic audit

Observations at least four standard deviations from the respective trait mean are highlighted but retained without automatic correction, transformation, winsorization, or exclusion.

Analysis sequence

The website is organized into four bilingual modules:

  1. Data preprocessing and audit
  2. Matrix construction and validation
  3. Fitting the eight prediction methods
  4. Results and model comparison

Português

Visão geral do projeto

Este projeto compara métodos de predição genômica para características de produção e qualidade dos frutos em mamoeiro utilizando marcadores SSR multialélicos.

O conjunto analítico validado contém:

  • 150 indivíduos;
  • 35 locos SSR originais;
  • 34 locos SSR mantidos;
  • 72 colunas de dosagem alélica mantidas;
  • 10 características fenotípicas;
  • bloco e família como efeitos fixos categóricos.

O identificador alfanumérico 144B é preservado durante todo o alinhamento dos dados.

Métodos de predição

Os oito métodos são:

  1. regressão ridge Bayesiana (BRR);
  2. BayesA;
  3. BayesB;
  4. BayesB com pi = 1e-5 como probabilidade de efeito nulo no artigo de referência;
  5. BayesC;
  6. Lasso Bayesiano (BL);
  7. RR-BLUP;
  8. GBLUP.

Como o BGLR define probIn como a probabilidade de efeito não nulo do marcador, a configuração especial do BayesB utiliza probIn = 1 - 1e-5.

Contrato das matrizes e da validação

A matriz de efeitos fixos X, a matriz centralizada de dosagens alélicas M e a matriz de relacionamento genômico aditivo G são construídas uma única vez com os 150 indivíduos alinhados.

As dimensões validadas são:

Matriz Dimensões Posto
X 150 × 19 19
M 150 × 72 38
G 150 × 150 38

As mesmas matrizes são utilizadas nos cinco folds estratificados por família. Cada fold possui 30 indivíduos de validação, 120 indivíduos de treinamento e 3 indivíduos de validação de cada família.

Para cada característica e fold, a validação cruzada altera somente o vetor fenotípico: os 30 fenótipos de validação são substituídos por NA. Os valores observados originais permanecem armazenados separadamente para o cálculo das métricas preditivas.

Auditoria fenotípica

Observações localizadas a pelo menos quatro desvios-padrão da média da respectiva característica são destacadas, mas mantidas sem correção, transformação, winsorização ou exclusão automática.

Sequência das análises

O site está organizado em quatro módulos bilíngues:

  1. Pré-processamento e auditoria dos dados
  2. Construção e validação das matrizes
  3. Ajuste dos oito métodos de predição
  4. Resultados e comparação dos modelos

Reproducibility / Reprodutibilidade

The complete dataset is processed once to define the analytical matrices. Cross-validation changes only the phenotype vector.

O conjunto completo é processado uma única vez para definir as matrizes analíticas. A validação cruzada altera somente o vetor fenotípico.
