Apresentação dos resultados

Costa, W. G.1

1. Objetivo

Este módulo transforma os resultados derivados no Módulo 04 em uma síntese visual e tabular para leitura científica. A sequência acompanha o raciocínio analítico: primeiro compara os sete métodos, depois apresenta a decisão por característica, ilustra diagnósticos MCMC e estabilidade entre folds e, por fim, mostra os rankings genômicos exploratórios e a recorrência entre características. Nenhuma tabela ou figura desta página constitui uma nova etapa de seleção ou inferência; elas apresentam resultados já definidos anteriormente.

2. Pacotes, resultados e padrão gráfico

Os pacotes utilizados têm funções distintas nesta etapa:

  • dplyr: organização, junção e transformação das tabelas de resultados;
  • ggplot2: construção das figuras de comparação e diagnóstico;
  • knitr: formatação das tabelas apresentadas na página;
  • here: construção de caminhos relativos ao projeto.
library(dplyr)  # Organiza e transforma as tabelas de resultados.
library(ggplot2) # Constrói as figuras da síntese.

O módulo consome dois objetos consolidados. models_object.rds fornece as configurações necessárias para localizar e interpretar as cadeias já salvas; module04_results.rds fornece todas as tabelas, decisões, rankings e correlações derivados no Módulo 04. Rótulos, cores, tamanho-base de fonte, dimensões e resolução de exportação são escolhas exclusivamente de apresentação e não entram em cálculos de desempenho, seleção ou inferência. A paleta fixa mantém a identidade visual de cada método ao longo da página.

format_list_pt <- function(x) {
  x <- as.character(x)
  n <- length(x)

  if (n == 0L) {
    return("nenhuma")
  }

  if (n == 1L) {
    return(x)
  }

  paste0(
    paste(x[-n], collapse = ", "),
    " e ",
    x[n]
  )
}

5. Cadeias MCMC dos métodos selecionados

Para cada característica, esta seção mostra apenas a cadeia posterior de \(\mu\) no fold 1 do método selecionado, sua média acumulada e sua densidade posterior. O fold 1 funciona como ilustração visual consistente entre características; ele não substitui os diagnósticos ESS/Geweke dos cinco folds nem constitui prova de convergência de todos os parâmetros do modelo.

models_object$settings$burn_in / models_object$settings$thin converte o burn-in da escala de iterações para a escala das amostras salvas. setNames(model_selection$Selected_method, model_selection$Trait) cria um vetor nomeado que recupera diretamente o método selecionado de cada característica. vector("list", length(traits)) pré-aloca as listas que receberão os resultados, e seq_along(traits) percorre os índices das dez características. Dentro do laço, scan() lê a cadeia salva de mu; seq.int(burn_in_saved + 1L, length(mu_full)) conserva somente as amostras posteriores ao burn-in. A sequência de iterações é reconstruída com seq.int(..., by = thin). cumsum(posterior_mu) / seq_along(posterior_mu) calcula a média acumulada usando toda a cadeia posterior, enquanto seq.int(..., by = 100L) reduz somente os pontos desenhados. Por fim, density(posterior_mu, n = 512) estima a densidade marginal usada na figura; n = 512 controla a resolução da curva, não o número de amostras MCMC.

# Converte o burn-in para a escala das amostras salvas e prepara os traces e densidades posteriores de mu.
burn_in_saved <-
  models_object$settings$burn_in /
  models_object$settings$thin

selected_method_lookup <- setNames(
  model_selection$Selected_method,
  model_selection$Trait
)

trace_parts <- vector("list", length(traits))
density_parts <- vector("list", length(traits))

for (trait_index in seq_along(traits)) {
  # Identifica a característica e o método selecionado.
  trait_name <- traits[trait_index]
  method_name <- selected_method_lookup[trait_name]

  # Localiza a cadeia de mu do primeiro fold.
  mu_file <- file.path(
    here("output", "models", "bglr"),
    trait_name,
    "F1",
    method_name,
    "bglr_mu.dat"
  )

  mu_full <- scan(mu_file, quiet = TRUE)

  # Remove as amostras correspondentes ao burn-in.
  posterior_mu <- mu_full[
    seq.int(burn_in_saved + 1L, length(mu_full))
  ]

  iteration <- seq.int(
    from = models_object$settings$burn_in + models_object$settings$thin,
    by = models_object$settings$thin,
    length.out = length(posterior_mu)
  )

  # Calcula a média acumulada e reduz a densidade de pontos do gráfico.
  running_mean <- cumsum(posterior_mu) / seq_along(posterior_mu)
  keep_index <- seq.int(1L, length(posterior_mu), by = 100L)

  trace_parts[[trait_index]] <- data.frame(
    Trait = trait_name,
    Method = method_name,
    Facet = paste0(trait_name, " — ", method_labels[method_name]),
    Iteration = iteration[keep_index],
    Posterior_mu = posterior_mu[keep_index],
    Running_mean = running_mean[keep_index]
  )

  # Estima a densidade posterior de mu para o método selecionado nesta característica.
  density_object <- density(posterior_mu, n = 512)

  density_parts[[trait_index]] <- data.frame(
    Trait = trait_name,
    Method = method_name,
    Facet = paste0(trait_name, " — ", method_labels[method_name]),
    x = density_object$x,
    y = density_object$y
  )
}

selected_mu_trace <- bind_rows(trace_parts)
selected_mu_density <- bind_rows(density_parts)

12. Síntese

A leitura final deve manter a hierarquia estabelecida ao longo da análise: desempenho OOF orienta a comparação preditiva; DIC, estabilidade entre folds e diagnósticos MCMC fornecem contexto complementar; rankings são produzidos apenas quando a direção OOF é positiva; e recorrência resume sobreposição entre rankings sem criar um índice multicaracterística. Todas as conclusões permanecem condicionadas à população de melhoramento representada, ao painel SSR disponível e ao desenho transdutivo da validação. Para uso operacional em seleção, os rankings OOF devem ser entendidos como evidência exploratória e não como substitutos de valores genéticos finais obtidos em uma etapa de predição destinada à decisão.
