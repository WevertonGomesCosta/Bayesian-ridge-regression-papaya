1. Objetivo

Este módulo apresenta os resultados derivados no Módulo 04. Nenhum modelo é reajustado, nenhuma métrica científica é recalculada e nenhuma decisão de seleção é redefinida.

O module04_results.rds é a fonte canônica dos resultados analíticos. O models_object.rds e os arquivos nativos do BGLR são utilizados somente para a representação gráfica das cadeias MCMC selecionadas.

A interpretação científica aprofundada fica reservada ao manuscrito.

5. Cadeias MCMC dos métodos selecionados

Como representação visual análoga à apresentada no artigo de referência, são mostradas a cadeia posterior de \(\mu\), sua média acumulada e a densidade posterior no primeiro fold do método selecionado para cada característica. Os diagnósticos numéricos completos permanecem no Módulo 03.

burn_in_saved <- models_object$settings$burn_in / models_object$settings$thin
selected_method_lookup <- setNames(model_selection$Selected_method, model_selection$Trait)

selected_mu_files <- file.path(
  here("output", "models", "bglr"),
  traits,
  "F1",
  unname(selected_method_lookup[traits]),
  "bglr_mu.dat"

if (!all(file.exists(selected_mu_files))) {

      "estão ausentes para pelo menos um método selecionado."

trace_parts <- vector("list", length(traits))
density_parts <- vector("list", length(traits))

for (trait_index in seq_along(traits)) {
  trait_name <- traits[trait_index]
  method_name <- selected_method_lookup[trait_name]

  mu_file <- file.path(
    here("output", "models", "bglr"),
    trait_name,
    "F1",
    method_name,
    "bglr_mu.dat"
  )

  mu_full <- scan(mu_file, quiet = TRUE)
  posterior_mu <- mu_full[seq.int(burn_in_saved + 1L, length(mu_full))]

  iteration <- seq.int(
    from = models_object$settings$burn_in + models_object$settings$thin,
    by = models_object$settings$thin,
    length.out = length(posterior_mu)
  )

  running_mean <- cumsum(posterior_mu) / seq_along(posterior_mu)
  keep_index <- seq.int(1L, length(posterior_mu), by = 100L)

  trace_parts[[trait_index]] <- data.frame(
    Trait = trait_name,
    Method = method_name,
    Facet = paste0(trait_name, " — ", method_labels[method_name]),
