Derivação dos resultados e seleção dos modelos

Costa, W. G.1

2026-08-27

1. Objetivo

A partir das predições, métricas e diagnósticos obtidos no Módulo 03, este módulo compara os sete métodos dentro de cada característica e deriva os resultados utilizados na seleção genômica.

São calculados o desempenho preditivo OOF, DIC e medidas relativas de suporte, a decisão do método por característica, a estabilidade entre folds, o tempo computacional, a herdabilidade e a acurácia no análogo RR-BLUP/BRR, os valores genômicos OOF, os rankings orientados, a seleção proporcional, a recorrência entre características e as correlações entre valores genômicos.

A direção de melhoramento é definida antes do ranking: aumentar MMCOM, PRODCOM, CF, DF, EP, FFC, FFP e SS; diminuir PRODEF e DCI.

2. Pacotes e resultados do ajuste dos modelos

Os pacotes utilizados têm funções distintas nesta etapa:

  • dplyr: agrupamento, junção, ordenação e resumo das tabelas de resultados;
  • tidyr: reorganização de tabelas entre formatos longo e largo;
  • knitr: formatação de tabelas em documentos R Markdown;
  • here: construção de caminhos relativos ao projeto.

3. Desempenho preditivo OOF

As estimativas OOF herdam o desenho estratificado por família dos Módulos 02 e 03. Elas quantificam a predição dentro da população de melhoramento representada e não estimam a generalização para famílias inteiramente novas.

As métricas principais são recalculadas com as 150 predições OOF de cada combinação característica × método. Cada indivíduo contribui uma única predição OOF para cada método.

group_by(Trait, Method) separa as predições por característica e método, e summarise() reduz as 150 linhas OOF de cada grupo às métricas agregadas. A correlação r, RMSE, MAE, viés e inclinação usam exatamente essas 150 predições. Para a correlação de Pearson, t_value = r * sqrt((N - 2) / (1 - r^2)) transforma r na estatística t com N - 2 graus de liberdade, e 2 * pt(..., lower.tail = FALSE) obtém o p-valor bicaudal. Esse p-valor é nominal e descritivo porque os conjuntos de treinamento dos folds se sobrepõem.

# Combina as predições OOF e calcula as métricas preditivas agregadas por característica e método.
pooled_metrics <- predictions |>
  group_by(Trait, Method) |>
  summarise(
    N = n(),
    r = cor(Observed, Predicted),
    RMSE = sqrt(mean((Observed - Predicted)^2)),
    MAE = mean(abs(Observed - Predicted)),
    Bias = mean(Predicted - Observed),
    Slope = cov(Observed, Predicted) / var(Predicted),
    .groups = "drop"
  ) |>
  mutate(
    t_value = r * sqrt((N - 2) / (1 - r^2)),
    p_value = 2 * pt(abs(t_value), df = N - 2, lower.tail = FALSE)
  ) |>
  select(-t_value)

# Resume os resultados no objeto `fold_summary`.
fold_summary <- metrics |>
  group_by(Trait, Method) |>
  summarise(
    Mean_DIC = mean(DIC),
    SD_DIC = sd(DIC),
    Mean_fold_r = mean(Correlation),
    SD_fold_r = sd(Correlation),
    Mean_fold_RMSE = mean(RMSE),
    SD_fold_RMSE = sd(RMSE),
    Mean_fold_MAE = mean(MAE),
    SD_fold_MAE = sd(MAE),
    .groups = "drop"

Há duas escalas de resumo nesta seção. pooled_metrics reúne as 150 predições OOF e fornece o desempenho global de cada característica × método; essa correlação agrupada é a referência principal para ordenar os vencedores preditivos. fold_summary preserva a variação entre os cinco folds e é usado posteriormente para avaliar estabilidade e construir as tolerâncias descritivas da regra de um erro-padrão.

4. DIC e suporte relativo dos métodos

Seguindo a lógica utilizada no estudo de referência (Silva et al. 2021), a diferença em relação ao menor DIC médio de cada característica é convertida em pesos relativos:

\[ \Delta_j=\overline{DIC}_j-\min_k(\overline{DIC}_k), \]

\[ Wprob_j=\frac{\exp(-\Delta_j/2)}{\sum_k\exp(-\Delta_k/2)}, \qquad ER_j=\frac{Wprob_{\max}}{Wprob_j}. \]

Wprob é utilizado aqui como um peso de suporte relativo derivado do DIC. Ele não é interpretado como uma probabilidade posterior calibrada de um modelo.

No código, Delta_DIC = Mean_DIC - min(Mean_DIC) fixa o melhor DIC médio da característica em zero. log_weight = -0.5 * Delta_DIC implementa o expoente da fórmula. Antes de exponenciar, max(log_weight) é subtraído de todos os log-pesos; essa translação melhora a estabilidade numérica sem alterar as razões relativas. Wprob = stable_weight / sum(stable_weight) normaliza os pesos para soma 1, e ER = max(Wprob) / Wprob expressa quantas vezes o maior peso relativo supera o peso de cada método.

# Integra desempenho por fold e DIC para construir as medidas usadas na comparação dos métodos.
model_comparison <- pooled_metrics |>
  left_join(fold_summary, by = c("Trait", "Method")) |>
  group_by(Trait) |>
  mutate(
    Delta_DIC = Mean_DIC - min(Mean_DIC),
    log_weight = -0.5 * Delta_DIC,
    stable_weight = exp(log_weight - max(log_weight)),
    Wprob = stable_weight / sum(stable_weight),
    # Calcula a razão de evidência relativa ao método de maior Wprob em cada característica.
    ER = max(Wprob) / Wprob
  ) |>
  ungroup() |>
  select(
    Trait, Method, Mean_DIC, SD_DIC, Delta_DIC, Wprob, ER,
    N, r, p_value, RMSE, MAE, Bias, Slope,
    Mean_fold_r, SD_fold_r, Mean_fold_RMSE, SD_fold_RMSE,
    Mean_fold_MAE, SD_fold_MAE
  ) |>
  arrange(match(Trait, traits), Delta_DIC)

5. Seleção do método por característica

A capacidade preditiva OOF é o critério principal. DIC fornece evidência complementar sobre ajuste e complexidade, enquanto a variação entre folds e os diagnósticos MCMC ajudam a avaliar a estabilidade da escolha.

Um método é considerado preditivamente competitivo quando sua média de correlação entre folds está até um erro-padrão abaixo da maior média e seu RMSE médio está até um erro-padrão acima do menor RMSE médio. O ajuste por DIC é considerado semelhante quando Delta_DIC <= 2. Esses limites definem um conjunto competitivo operacional, e não um teste formal de equivalência.

Quando RR-BLUP/BRR pertence a esse conjunto competitivo e não apresenta flags de convergência, ele é preferido como referência de contração homogênea e de parametrização mais simples. Caso contrário, é utilizado o melhor candidato competitivo sem flags; se não houver candidato elegível pela regra, o vencedor preditivo é mantido como escolha provisória para revisão.

5.3 Conjunto competitivo

A regra de um erro-padrão é aplicada à correlação e ao RMSE médios entre folds. Para cada característica, a tolerância de correlação usa o desvio-padrão entre folds do método com a maior Mean_fold_r, dividido por sqrt(5); analogamente, a tolerância de RMSE usa o método com a menor Mean_fold_RMSE. Um candidato precisa satisfazer simultaneamente as duas tolerâncias.

which.max(Mean_fold_r) localiza o método que define a referência de correlação e which.min(Mean_fold_RMSE) localiza a referência de RMSE. Como N_FOLDS = 5, dividir o desvio-padrão correspondente por sqrt(N_FOLDS) produz a tolerância descritiva usada na regra. Um método precisa satisfazer simultaneamente Within_one_SE_r e Within_one_SE_RMSE para ser classificado como preditivamente competitivo.

Em seguida, Delta_DIC <= 2 restringe o conjunto a ajustes com DIC operacionalmente semelhante e qualquer flag entre os diagnósticos monitorados impede a classificação como candidato automático. Como os conjuntos de treinamento se sobrepõem entre folds, esses erros-padrão são tolerâncias descritivas e não são interpretados como erros-padrão inferenciais de amostras independentes.

# Combina desempenho, DIC e diagnósticos MCMC para definir o conjunto competitivo de cada característica.
model_selection_support <- model_comparison |>
  left_join(
    convergence_by_trait_method,
    by = c("Trait", "Method")
  ) |>
  left_join(
    predictive_winners |>
      select(Trait, Predictive_winner),
    by = "Trait"
  ) |>
  group_by(Trait) |>
  mutate(
    # Referências para a regra de um erro-padrão.
    Best_mean_fold_r = max(Mean_fold_r, na.rm = TRUE),
    Best_mean_fold_r_SE =
      SD_fold_r[which.max(Mean_fold_r)] / sqrt(N_FOLDS),
    Best_mean_fold_RMSE = min(Mean_fold_RMSE, na.rm = TRUE),
    Best_mean_fold_RMSE_SE =
      SD_fold_RMSE[which.min(Mean_fold_RMSE)] / sqrt(N_FOLDS),

    # Competitividade preditiva.
    Within_one_SE_r =
      Mean_fold_r >= Best_mean_fold_r - Best_mean_fold_r_SE,
    Within_one_SE_RMSE =
      Mean_fold_RMSE <= Best_mean_fold_RMSE + Best_mean_fold_RMSE_SE,
    Predictively_competitive =
      Within_one_SE_r & Within_one_SE_RMSE,

    # Suporte complementar por DIC e convergência.
    DIC_competitive_threshold = DIC_COMPETITIVE_THRESHOLD,
    DIC_competitive = Delta_DIC <= DIC_COMPETITIVE_THRESHOLD,
    Competitive_for_selection =
      Predictively_competitive & DIC_competitive,
    Convergence_review = Parameters_flagged > 0,
    Automatic_candidate =
      Competitive_for_selection & !Convergence_review,

    # Resumo do conjunto de candidatos em cada característica.
    Competitive_set_n = sum(Competitive_for_selection),
    Automatic_candidate_n = sum(Automatic_candidate),
    RRBLUP_competitive = any(
      Method == "RRBLUP" & Competitive_for_selection
    ),
    RRBLUP_automatic_candidate = any(
      Method == "RRBLUP" & Automatic_candidate
    ),
    Automatic_selection_available = any(Automatic_candidate),

    # RR-BLUP recebe prioridade apenas dentro do conjunto automático.

5.4 Escolha do método

Entre os candidatos automáticos, RR-BLUP recebe prioridade como escolha explícita de parcimônia e referência de contração homogênea; essa prioridade não implica superioridade estatística universal do RR-BLUP. Se RR-BLUP não for candidato automático, os demais são ordenados pela correlação OOF agrupada, seguida de RMSE, MAE e DIC. Na ausência de qualquer candidato automático, o vencedor preditivo é mantido apenas como escolha provisória que requer revisão.

No código, filter(Automatic_candidate) mantém somente os métodos que passaram simultaneamente pelos critérios preditivos, de DIC e de convergência monitorada. slice(1L) retém o primeiro método após a ordenação de prioridade. Em seguida, coalesce(Automatic_selected_method, Predictive_winner) usa o candidato automático quando ele existe e, apenas quando esse valor é ausente, recorre ao vencedor preditivo provisório.

8. Análogo de herdabilidade baseado em marcadores e acurácia ajustada no RR-BLUP/BRR

Seguindo Silva et al. (Silva et al. 2021), um análogo de variância aditiva baseado em marcadores é obtido a partir da variância comum dos marcadores e do denominador \(\sum 2pq\). A acurácia ajustada por fold é definida como \(r_f/\sqrt{H_f^2}\). O \(H^2\) resultante é apresentado como um análogo de herdabilidade baseado no modelo, e não como uma estimativa clássica independente de herdabilidade no sentido restrito. A quantidade denominada Predictive_accuracy é uma razão derivada, r_f/sqrt(H_f^2), e não uma correlação observada diretamente entre valor genético verdadeiro e predito. Por depender de estimativas amostrais de r_f e H_f^2, ela pode ser negativa ou exceder 1; por isso deve ser interpretada como índice de acurácia ajustada segundo essa definição, e não como uma medida necessariamente limitada ao intervalo [0, 1].

10. Ranking exploratório proporcional de candidatos por característica

Os rankings de candidatos são apresentados para as características cujo método selecionado possui correlação OOF positiva. Os p-valores nominais permanecem descritivos e não determinam se um ranking é produzido. Correlações positivas com p >= 0,05 são mantidas explicitamente como sinais fracos/exploratórios e não devem ser interpretadas como utilidade preditiva demonstrada. Em cada característica com OOF positivo, são listados os 20% de indivíduos com maior escore orientado; essa proporção é uma regra configurável desta análise, e não uma intensidade ótima estimada. Com 150 candidatos disponíveis, 20% correspondem a 30 indivíduos. Para características cujo objetivo é diminuir, o escore é o negativo do valor genômico.

A ordenação usa IND apenas como critério secundário determinístico quando dois escores são exatamente iguais. A proporção selecionada permanece fixa mesmo se houver empate no limite; Exact_boundary_tie = TRUE apenas informa que o último incluído e o primeiro excluído possuem o mesmo escore e, portanto, não há evidência genômica para distingui-los naquele corte.

ceiling(SELECTION_PROPORTION * N_available) arredonda para cima o número correspondente à proporção definida, enquanto pmax(1L, ...) garante pelo menos um candidato quando houver indivíduos disponíveis. Na tabela de corte, lead(Selection_score) desloca o escore seguinte para a mesma linha do candidato atual; first(N_selected) identifica a posição do último selecionado e permite comparar diretamente esse escore com o primeiro não selecionado.

11. Recorrência entre características

A recorrência é descritiva: entre as características com correlação OOF positiva, conta em quantas cada indivíduo aparece entre os 20% mais favoráveis. Selection_frequency divide essa contagem pelo número de características com OOF positivo, e não necessariamente pelas dez características originais. Sinais OOF positivos fracos permanecem exploratórios. Não são usados pesos e não é construído índice de seleção multicaracterística; aparecer em várias listas não equivale a demonstrar superioridade multicaracterística conjunta.

As classes de recorrência são convenções descritivas: alta para quatro ou mais características, intermediária para três, ampla para duas, específica para uma e nenhuma para zero. O objeto multitrait_candidates conserva indivíduos recorrentes em pelo menos duas características para não descartar informação potencialmente útil nos módulos seguintes. Esses pontos de corte organizam a apresentação e não são limiares de significância estatística.

Após o left_join() com todos os indivíduos, replace_na() transforma contagens ausentes em zero e listas de características ausentes em texto vazio. Selection_frequency = N_traits / length(positive_oof_traits) usa como denominador apenas as características com OOF positivo. pivot_wider() reorganiza os ranks específicos para uma coluna por característica, e filter(N_traits >= 2L) define o objeto completo de candidatos recorrentes usado nas etapas seguintes.

# Conta a recorrência dos indivíduos entre os rankings exploratórios das características com OOF positivo.
recurrence_counts <- selected_individuals_by_trait |>
  arrange(match(Trait, traits), Rank) |>
  group_by(IND, FAM) |>
  summarise(
    N_traits = n(),
    Traits = paste(Trait, collapse = ", "),
    Best_rank = min(Rank),
    Mean_rank_present = mean(Rank),
    .groups = "drop"
  )

# Integra a contagem de recorrência aos metadados e calcula frequência e classe de recorrência.
multitrait_recurrence <- matrices_object$metadata |>
  select(IND, FAM) |>
  left_join(recurrence_counts, by = c("IND", "FAM")) |>
  mutate(
    N_traits = tidyr::replace_na(N_traits, 0L),
    Traits = tidyr::replace_na(Traits, ""),
    Best_rank = case_when(
      N_traits == 0L ~ NA_integer_,
      TRUE ~ Best_rank
    ),
    Mean_rank_present = case_when(
      N_traits == 0L ~ NA_real_,
      TRUE ~ Mean_rank_present
    ),
    Selection_frequency = N_traits / length(positive_oof_traits),
    # Classifica a recorrência por número de características; os cortes são descritivos.
    Recurrence_class = case_when(
      N_traits >= 4L ~ "high_4plus",
      N_traits == 3L ~ "intermediate_3",
      N_traits == 2L ~ "broad_2",
      N_traits == 1L ~ "specific_1",
      TRUE ~ "none_0"
    )
  ) |>
  arrange(desc(N_traits), FAM, IND)
