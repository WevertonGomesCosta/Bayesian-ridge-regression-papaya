Derivação dos resultados e seleção dos modelos

Costa, W. G.1

2026-08-24

1. Objetivo

A partir das predições, métricas e diagnósticos obtidos no Módulo 03, este módulo compara os sete métodos dentro de cada característica e deriva os resultados utilizados na seleção genômica.

São calculados o desempenho preditivo OOF, DIC e medidas relativas de suporte, a decisão do método por característica, a estabilidade entre folds, o tempo computacional, a herdabilidade e a acurácia no análogo RR-BLUP/BRR, os valores genômicos OOF, os rankings orientados, a seleção proporcional, a recorrência entre características e as correlações entre valores genômicos.

A direção de melhoramento é definida antes do ranking: aumentar MMCOM, PRODCOM, CF, DF, EP, FFC, FFP e SS; diminuir PRODEF e DCI.

3. Desempenho preditivo OOF

As estimativas OOF herdam o desenho estratificado por família dos Módulos 02 e 03. Elas quantificam a predição dentro da população de melhoramento representada e não estimam a generalização para famílias inteiramente novas.

As métricas principais são recalculadas com as 150 predições fora da amostra de cada combinação característica × método. Cada indivíduo contribui uma única predição OOF para cada método.

pooled_metrics <- predictions |>
  group_by(Trait, Method) |>
  summarise(
    N = n(),
    r = cor(Observed, Predicted),
    RMSE = sqrt(mean((Observed - Predicted)^2)),
    MAE = mean(abs(Observed - Predicted)),
    Bias = mean(Predicted - Observed),
    Slope = cov(Observed, Predicted) / var(Predicted),
    .groups = "drop"
  ) |>
  mutate(
    t_value = r * sqrt((N - 2) / (1 - r^2)),
    p_value = 2 * pt(abs(t_value), df = N - 2, lower.tail = FALSE)
  ) |>
  select(-t_value)

fold_summary <- metrics |>
  group_by(Trait, Method) |>
  summarise(
    Mean_DIC = mean(DIC),
    SD_DIC = sd(DIC),
    Mean_fold_r = mean(Correlation),
    SD_fold_r = sd(Correlation),
    Mean_fold_RMSE = mean(RMSE),
    SD_fold_RMSE = sd(RMSE),
    Mean_fold_MAE = mean(MAE),
    SD_fold_MAE = sd(MAE),

  )

4. DIC e suporte relativo dos métodos

Seguindo a lógica utilizada no estudo de referência (Silva et al. 2021), a diferença em relação ao menor DIC médio de cada característica é convertida em pesos relativos:

\[ \Delta_j=DIC_j-\min(DIC), \]

\[ Wprob_j=\frac{\exp(-\Delta_j/2)}{\sum_k\exp(-\Delta_k/2)}, \qquad ER_j=\frac{Wprob_{\max}}{Wprob_j}. \]

Wprob é utilizado aqui como um peso de suporte relativo derivado do DIC. Ele não é interpretado como uma probabilidade posterior calibrada de um modelo.

model_comparison <- pooled_metrics |>
  left_join(fold_summary, by = c("Trait", "Method")) |>
  group_by(Trait) |>
  mutate(
    Delta_DIC = Mean_DIC - min(Mean_DIC),
    log_weight = -0.5 * Delta_DIC,
    stable_weight = exp(log_weight - max(log_weight)),
    Wprob = stable_weight / sum(stable_weight),
    ER = max(Wprob) / Wprob
  ) |>
  ungroup() |>
  select(
    Trait, Method, Mean_DIC, SD_DIC, Delta_DIC, Wprob, ER,

    Mean_fold_r, SD_fold_r, Mean_fold_RMSE, SD_fold_RMSE,
    Mean_fold_MAE, SD_fold_MAE
  ) |>
  arrange(match(Trait, traits), Delta_DIC)

5. Seleção do método por característica

A capacidade preditiva OOF é o critério principal. DIC fornece evidência complementar sobre ajuste e complexidade, enquanto a variação entre folds e os diagnósticos MCMC ajudam a avaliar a estabilidade da escolha.

Um método é considerado preditivamente competitivo quando sua média de correlação entre folds está até um erro-padrão abaixo da maior média e seu RMSE médio está até um erro-padrão acima do menor RMSE médio. O ajuste por DIC é considerado semelhante quando Delta_DIC <= 2. Esses limites definem um conjunto competitivo operacional, e não um teste formal de equivalência.

Quando RR-BLUP/BRR pertence a esse conjunto competitivo e não apresenta flags de convergência, ele é preferido como referência de contração homogênea e de parametrização mais simples. Caso contrário, é utilizado o melhor candidato competitivo sem flags; se não houver candidato elegível pela regra, o vencedor preditivo é mantido como escolha provisória para revisão.

5.3 Conjunto competitivo

A regra de um erro-padrão é aplicada à correlação e ao RMSE médios entre folds. Em seguida, o limite Delta_DIC <= 2 e os diagnósticos MCMC definem os candidatos elegíveis pela regra. Como os conjuntos de treinamento se sobrepõem entre folds, esses erros-padrão são tolerâncias descritivas e não são interpretados como erros-padrão inferenciais de amostras independentes.

model_selection_support <- model_comparison |>
  left_join(
    convergence_by_trait_method,
    by = c("Trait", "Method")
  ) |>
  left_join(
    predictive_winners |>
      select(Trait, Predictive_winner),
    by = "Trait"
  ) |>
  group_by(Trait) |>
  mutate(
    # Referências para a regra de um erro-padrão.
    Best_mean_fold_r = max(Mean_fold_r, na.rm = TRUE),
    Best_mean_fold_r_SE =
      SD_fold_r[which.max(Mean_fold_r)] / sqrt(N_FOLDS),
    Best_mean_fold_RMSE = min(Mean_fold_RMSE, na.rm = TRUE),
    Best_mean_fold_RMSE_SE =
      SD_fold_RMSE[which.min(Mean_fold_RMSE)] / sqrt(N_FOLDS),

    # Competitividade preditiva.
    Within_one_SE_r =
      Mean_fold_r >= Best_mean_fold_r - Best_mean_fold_r_SE,
    Within_one_SE_RMSE =
      Mean_fold_RMSE <= Best_mean_fold_RMSE + Best_mean_fold_RMSE_SE,
    Predictively_competitive =
      Within_one_SE_r & Within_one_SE_RMSE,

    # Suporte complementar por DIC e convergência.
    DIC_competitive_threshold = DIC_COMPETITIVE_THRESHOLD,
    DIC_competitive = Delta_DIC <= DIC_COMPETITIVE_THRESHOLD,
    Competitive_for_selection =
      Predictively_competitive & DIC_competitive,
    Convergence_review = Parameters_flagged > 0,
    Automatic_candidate =
      Competitive_for_selection & !Convergence_review,

    # Resumo do conjunto de candidatos em cada característica.
    Competitive_set_n = sum(Competitive_for_selection),
    Automatic_candidate_n = sum(Automatic_candidate),
    RRBLUP_competitive = any(
      Method == "RRBLUP" & Competitive_for_selection
    ),
    RRBLUP_automatic_candidate = any(
      Method == "RRBLUP" & Automatic_candidate
    ),
    Automatic_selection_available = any(Automatic_candidate),

    # RR-BLUP recebe prioridade apenas dentro do conjunto automático.
    Selection_priority = case_when(
      Automatic_candidate & Method == "RRBLUP" ~ 1L,
      Automatic_candidate ~ 2L,
      TRUE ~ 3L
    )
  ) |>
  ungroup() |>
  arrange(
    match(Trait, traits),
    Selection_priority,
    desc(r),
    RMSE,
    MAE,
    Mean_DIC
  )

5.4 Escolha do método

Entre os candidatos automáticos, RR-BLUP recebe prioridade. Na ausência de candidato automático, o vencedor preditivo é mantido como escolha provisória.

  filter(Automatic_candidate) |>
  group_by(Trait) |>
  arrange(
    Selection_priority,
    desc(r),
    RMSE,
    MAE,
    Mean_DIC,

  ungroup() |>
  transmute(
    Trait,

      Selection_requires_review ~ "provisional_review_required",

8. Análogo de herdabilidade baseado em marcadores e acurácia ajustada no RR-BLUP/BRR

Seguindo Silva et al. (Silva et al. 2021), um análogo de variância aditiva baseado em marcadores é obtido a partir da variância comum dos marcadores e do denominador \(\sum 2pq\). A acurácia ajustada por fold é definida como \(r_f/\sqrt{H_f^2}\). O \(H^2\) resultante é apresentado como um análogo de herdabilidade baseado no modelo, e não como uma estimativa clássica independente de herdabilidade no sentido restrito.

rrblup_variance_components <- convergence |>
  filter(
    Method == "RRBLUP",
    Parameter %in% c("Residual_variance", "Marker_variance")
  ) |>
  select(Run_id, Trait, Fold, Method, Parameter, Posterior_mean) |>
  pivot_wider(names_from = Parameter, values_from = Posterior_mean)

rrblup_fold_correlations <- metrics |>
  filter(Method == "RRBLUP") |>
  select(Trait, Fold, Correlation)

rrblup_heritability_by_fold <- rrblup_variance_components |>
  left_join(rrblup_fold_correlations, by = c("Trait", "Fold")) |>
  mutate(
    Marker_variance_denominator = matrices_object$denominator,
    Additive_variance = Marker_variance * Marker_variance_denominator,
    H2 = Additive_variance / (Additive_variance + Residual_variance),
    Predictive_accuracy = Correlation / sqrt(H2)
  ) |>
  arrange(match(Trait, traits), Fold)

rrblup_heritability_summary <- rrblup_heritability_by_fold |>

    SD_predictive_accuracy = sd(Predictive_accuracy),

  arrange(match(Trait, traits))

Os rankings de candidatos são apresentados para as características cujo método selecionado possui correlação OOF positiva. Os p-valores nominais permanecem descritivos e não determinam se um ranking é produzido. Correlações positivas com p >= 0,05 são mantidas explicitamente como sinais fracos/exploratórios e não devem ser interpretadas como utilidade preditiva demonstrada. 11. Recorrência entre características

A recorrência é descritiva: entre as características com correlação OOF positiva, conta em quantas cada indivíduo aparece entre os 20% mais favoráveis. Sinais OOF positivos fracos permanecem exploratórios. Não são usados pesos e não é construído índice de seleção multicaracterística.

recurrence_counts <- selected_individuals_by_trait |>
  arrange(match(Trait, traits), Rank) |>
  group_by(IND, FAM) |>
  summarise(
    N_traits = n(),
    Traits = paste(Trait, collapse = ", "),
    Best_rank = min(Rank),
    Mean_rank_present = mean(Rank),
    .groups = "drop"
  )

multitrait_recurrence <- matrices_object$metadata |>
  select(IND, FAM) |>
  left_join(recurrence_counts, by = c("IND", "FAM")) |>
  mutate(
    N_traits = tidyr::replace_na(N_traits, 0L),
    Traits = tidyr::replace_na(Traits, ""),
    Best_rank = case_when(
      N_traits == 0L ~ NA_integer_,
      TRUE ~ Best_rank
    ),
    Mean_rank_present = case_when(
      N_traits == 0L ~ NA_real_,
      TRUE ~ Mean_rank_present
    ),
    Selection_frequency = N_traits / length(positive_oof_traits),
    Recurrence_class = case_when(
      N_traits >= 4L ~ "high_4plus",
      N_traits == 3L ~ "intermediate_3",
      N_traits == 2L ~ "broad_2",
      N_traits == 1L ~ "specific_1",
      TRUE ~ "none_0"
    )
  ) |>
  arrange(desc(N_traits), FAM, IND)

recurrence_distribution <- multitrait_recurrence |>
  count(N_traits, Recurrence_class, name = "N_individuals") |>
  mutate(
    Proportion_of_population =
      N_individuals / nrow(matrices_object$metadata)
  ) |>
  arrange(desc(N_traits))

candidate_rank_wide <- selected_individuals_by_trait |>
  semi_join(
    multitrait_recurrence |>
      filter(N_traits >= 2L),

  select(IND, FAM, Trait, Rank) |>
  pivot_wider(
    names_from = Trait,
    values_from = Rank,

multitrait_candidates <- multitrait_recurrence |>
  filter(N_traits >= 2L) |>
  left_join(candidate_rank_wide, by = c("IND", "FAM")) |>
